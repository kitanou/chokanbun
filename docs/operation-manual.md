# 超漢文 OS 操作マニュアル（試作版）

- 対象: `kitanou/chokanbun` の現行実装
- 実行環境: macOS + Homebrew + QEMU（AArch64）
- 状態: 開発中の OS に対する操作手引き。完成版 OS や GUI の操作説明ではない
- 関連文書: [README](../README.md)・[漢殻コマンド一覧](shell-commands.md)・[篇藏設計](design-pianfs.md)・[永続化設計](design-persistence.md)

## 1. はじめに

超漢文 OS は、機械漢文で記述する独立 OS の研究開発プロジェクトです。現在は QEMU の AArch64 仮想機で起動し、シリアル端末から「漢殻（かんかく）」を操作します。

この版には通常のデスクトップ GUI はありません。操作は文字入力が中心です。機能・コマンド・制約は開発中に変更されることがあります。

## 2. 起動する

### 2.1 必要なツール

Homebrew が利用できる macOS で、必要なツールをインストールします。

```sh
brew install llvm lld qemu
```

### 2.2 ビルドとテスト

リポジトリのルートで実行します。

```sh
make
make test
```

- `make` は機械漢文コンパイラをビルドします。
- `make test` はコンパイラ、カーネルの生成、QEMU を使ったテストを実行します。
- テストが失敗した場合は、最初に失敗したケースとログを確認してください。

### 2.3 対話モードで起動

篇藏の保存・復元も試す場合は、永続化用ディスクイメージを用意する `make run` を使います。

```sh
make run
```

直接起動する場合は、次の方法もあります（永続化用のディスクを接続しないため、`同` による保存は利用できません）。

```sh
make test
qemu-system-aarch64 -M virt,gic-version=2 -cpu cortex-a57 -nographic \
  -serial mon:stdio -kernel tests/output/kernel.elf
```

起動後は次の点に注意してください。

1. 起動ログのあと、**最初の 1 行は起動時の読込テストに使われます**。例として `KANBUN` と入力して Enter を押します。
2. 続いて `殻>` が表示されたら、漢殻の命令を入力します。
3. コマンドは原則として 1 行ずつ入力します。
4. QEMU を終了するには `Ctrl-A` を押し、その後 `X` を押します。

## 3. 漢殻の基本操作

コマンド名と引数の間は半角スペースで区切ります。コマンドの先頭にある漢字で命令が選ばれます。

| 命令 | 書式 | 説明 |
|---|---|---|
| `助` | `助` | コマンド一覧を表示 |
| `響` | `響 文` | 指定した文を表示 |
| `目` | `目` | 現在の章にある篇（ファイル）の一覧を表示 |
| `讀` | `讀 名` | 篇の内容を表示 |
| `書` | `書 名 文` | 篇を作成し、文を書き込む。既存の篇がある場合は内容を空にして書き直す |
| `削` | `削 名` | 篇を削除 |
| `章` | `章 パス` | 章（ディレクトリ相当）を作成 |
| `移` | `移 パス` | 現在の章を変更。相対指定 `..` は親の章 |
| `在` | `在` | 現在の章の絶対パスを表示 |
| `改` | `改 旧 新` | 篇の名前を変更。新しいパスに別の章を指定すると移動もできる |
| `同` | `同` | 篇藏と録層 FS 0 の状態を接続ディスクへ保存 |
| `終` | `終` | 現在の漢殻を終了 |

### 3.1 最初に試す

```text
殻> 助
殻命令一覧
殻> 響 超漢文起動
殻響:超漢文起動
殻> 目
殻目:史記
殻目:詩経
```

初期登録された篇には `史記` と `詩経` があります。起動時の自己テストにより、`史記` の内容に「追記」が加わっている場合があります。

### 3.2 篇を読む・作る・削除する

```text
殻> 讀 詩経
殻讀:關關雎鳩、在河之洲
殻> 書 筆記 天地玄黄
殻書 0x000000000000000c
殻> 讀 筆記
殻讀:天地玄黄
殻> 目
殻目:史記
殻目:筆記
殻目:詩経
殻> 削 筆記
殻削:筆記
```

`書` は既存の篇に対しても内容を空にしてから書き込みます。残したい本文がある篇に、うっかり同じ名前で `書` を実行しないでください。

### 3.3 章を作り、移動する

```text
殻> 章 天地/家/資料
殻章:天地/家/資料
殻> 移 天地/家/資料
殻移:天地/家/資料
殻> 在
殻在:天地/家/資料
殻> 書 読書メモ 今日の記録
殻書 0x0000000000000012
殻> 移 ..
殻移:..
```

パスの区切りは半角の `/` です。絶対パスは `天地` から始めます。相対パスは現在の章を基準に解決します。`..` は親の章を表します。

## 4. 外部命令を実行する

組み込み命令以外の名前を入力すると、漢殻は `天地/術` に登録された外部命令（漢像）を探して子行程として起動します。引数は半角スペースで区切って渡します。

例:

```text
殻> 問安
殻> 數 12
```

実行できる命令はビルド時に組み込まれたものに限られます。任意の macOS コマンドがそのまま実行できるわけではありません。実装されている外部命令は、リポジトリの [漢殻コマンド一覧](shell-commands.md) と `user/` 以下を参照してください。

## 5. 保存と次回起動時の復元

永続化は、QEMU に接続された virtio-blk ディスク `vda` にチェックポイントを書き出す仕組みです。通常の対話中に自動保存はされません。

1. `make run` で起動します。
2. 保存したい篇を作成・編集します。
3. `同` を入力します。
4. `殻同 保存した` と表示されたことを確認します。
5. QEMU を終了し、同じディスクイメージを使って再度 `make run` します。
6. 保存した篇を `目` や `讀 名` で確認します。

注意:

- `同` は篇藏と録層 FS 0 の状態を保存します。行程、開いている柄、ロックなどの実行時状態は保存しません。
- ディスク装置がない場合や容量が不足する場合は保存に失敗します。
- `make clean` は生成物を削除するため、保存用ディスクイメージも削除される可能性があります。必要なデータがある場合は実行前に注意してください。
- 保存は明示操作です。終了前に `同` を実行していない変更は、再起動後に失われる可能性があります。

## 6. 名前空間と制約

現在の篇藏実装には、開発版として次の上限があります。

- 篇の総数: 最大 128 件
- 1 つの章の子: 最大 32 件
- 1 篇の本文: 最大 4 KiB
- 名前: 最大 32 バイト
- パス全体: 最大 128 バイト
- 章の深さ: 根の下 8 段まで

UTF-8 では漢字 1 字が通常 3 バイトなので、名前の上限は「漢字 32 字」ではありません。名前はバイト数で制限されます。

予約された章には `天地/家`（利用者データ）、`天地/典`（初期文書）、`天地/法`（設定）、`天地/器`（装置）、`天地/術`（外部命令）、`天地/志`（記録）があります。予約領域の一部は通常の操作で変更・削除できません。

## 7. エラー表示の見方

- `殻無`: 指定した篇が見つからない。
- `殻不明`: 組み込み命令でも、実行可能な外部命令でもない。
- `殻用法 ...`: 引数が不足しているなど、コマンドの書式が正しくない。
- `殻誤 0x...`: 操作に失敗した。後ろの値はエラーコードを 64 ビット表記したもの。
- `殻碼 0x...`: 外部命令の終了コード。

よくある原因:

| 状況 | 確認すること |
|---|---|
| 篇が見つからない | `目` で一覧を確認し、名前・パスの綴りを確認 |
| `殻誤` が出る | 予約領域、名前やパスの長さ、篇の上限、開いたままの篇などを確認 |
| `同` で保存できない | `make run` で起動したか、ディスク装置と容量があるか確認 |
| 入力しても命令が実行されない | `殻>` が表示されているか、先頭の漢字と半角スペースを確認 |
| 起動後すぐに入力した内容がコマンド扱いされない | 最初の 1 行は起動時の読込テストに使われるため、もう一度 `殻>` で入力 |

エラーコードの詳細表は [漢殻コマンド一覧](shell-commands.md) を参照してください。

## 8. 終了する

漢殻の `終` は漢殻の行程を終了させます。開発中の構成では、これを通常の安全なシャットダウンと同じものと考えないでください。QEMU 自体を終了する場合は、端末で `Ctrl-A` のあと `X` を押します。

## 9. 現時点でできないこと

この文書の対象版では、次の機能は完成した製品機能として提供されていません。

- GUI デスクトップによる操作
- 実機への一般的なインストール
- BTRON3 仕様への完全準拠
- 機械漢文製ブートローダーとセルフホスティング
- 任意の外部 OS コマンドや Linux アプリの実行
- 篇藏の自動保存
