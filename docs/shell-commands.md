# 漢殻コマンド一覧

QEMU `virt` で漢極を起動すると、甲行程が init 兼 漢殻として動く（実装は `kernel/kernel.mkn` の `民殻`）。
このページは漢殻の命令と、その下で使う漢令（システムコール）の一覧である。

## 起動と入力

```bash
make test        # tests/output/kernel.elf を作る
qemu-system-aarch64 -M virt,gic-version=2 -cpu cortex-a57 -nographic \
  -serial mon:stdio -kernel tests/output/kernel.elf
```

- 起動時の読込テストが**最初の 1 行**を消費する。ログが出たら早めに 1 行（例: `KANBUN`）を入力して Enter を押す。以降は漢殻が行を読む。
- 行末は CR（端末の Enter）も LF（パイプ入力）も受け付ける。入力は 1 文字ずつ画面へ反響する。
- 漢殻は入力が来るまで待ち続ける。QEMU の終了は `Ctrl-A` のあと `X`。

## 漢殻の命令

命令は先頭の漢字 1 字で選び、引数は半角スペースで区切る。

| 命令 | 書式 | 動作 | 出力 |
|---|---|---|---|
| `響` | `響 文` | 文をそのまま出力する | `殻響:文` |
| `讀` | `讀 名` | 典籍 `名` を開き、内容を表示する | `殻讀:内容` / 無い名前は `殻無` |
| `目` | `目` | 典籍の名前を一覧する | 1 件ごとに `殻目:名` |
| `書` | `書 名 文` | 典籍 `名` を作り、`文` を書く。既にあれば内容を空にして書き直す | `殻書 0x…`（書いたバイト数）/ 失敗は `殻誤 0x…` |
| `削` | `削 名` | 典籍 `名` を削る。開かれていれば削れない | `殻削:名` / 失敗は `殻誤 0x…` |
| `章` | `章 パス` | 章（ディレクトリ）を作る（漢令 28 章作） | `殻章:パス` / 失敗は `殻誤 0x…` |
| `移` | `移 パス` | 現在章を移る。`..` で一つ上へ（漢令 32 章移） | `殻移:パス` / 失敗は `殻誤 0x…` |
| `在` | `在` | 現在章の絶対パスを表示する（漢令 33 章名） | `殻在:天地/典` など |
| `改` | `改 旧 新` | 篇の名を替える。新のパスが別の章なら、その章へ移す（漢令 25 名替） | `殻改:旧→新` / 失敗は `殻誤 0x…` |
| `助` | `助` | 命令一覧を表示する | `殻命令一覧` 以下 |
| 外部命令 | `名 引数…` | 上のどれでもなければ、名前の漢像を子行程として起動し、終了を待つ。引数は空白で分けて argv に渡る。終了コードが 0 以外なら表示する | 子の出力 / `殻碼 0x…`（終了コード）。像が無ければ `殻不明` |
| `終` | `終` | 漢殻を終える | `殻終` |

どれにも当たらない入力は `殻不明`。`書` の引数が足りないときは `殻用法 書 名 文`、`改` は `殻用法 改 旧 新`。

漢殻は先頭の漢字 1 字（`在`・`目`・`助` は 1 字だけの行、`終` は先頭の字）で組み込みの命令を選ぶため、外部命令の名がこれらの字で始まると組み込みの方が選ばれる。いまの外部命令（問安・數・識試・名試・時試・信試・利試・強試・同試・緩試・録試・篇試）はどれとも重ならない。

```
殻移:天地/典
```

## 篇藏（ファイル）の制約

漢殻の `讀`・`書`・`削`・`目`・`章`・`移`・`在`・`改` は篇藏（[design-pianfs.md](design-pianfs.md)）の上で動く。名前は**現在章**（起動時は `天地/典`）からの相対パスとして解決し、`天地/家/筆記` のような絶対パスも書ける。

| 項目 | 値 |
|---|---|
| 篇の数 | 全体で 128、1 つの章の子は 32 まで |
| 名前の長さ | 32 バイトまで（漢字 1 字は UTF-8 で 3 バイトなので 10 字まで）。パスは 128 バイト、深さは根の下 8 段 |
| 本文の大きさ | 1 件 4 KiB まで |
| 永続性 | なし（RAM 上のみ。再起動で消える） |
| 予約された章 | `天地/家`（利用者）・`典`（文書、漢殻の現在章）・`法`（設定）・`器`（装置。`器/盤` はコンソール）・`術`（外部命令）・`志`（追記専用） |
| 初期登録 | `天地/典/史記`（黄帝者、少典之子、姓公孫）・`天地/典/詩経`（關關雎鳩、在河之洲） |
| 一覧 | `目` は現在章の子を名のバイト列の昇順で出す |

起動時の自己テスト（`民籍試`）が `史記` に `追記` を書き足すため、起動直後の `讀 史記` は「黄帝者、少典之子、姓公孫追記」になる。外部命令は `天地/術` の篇として登録され、漢殻は名前でそこから起動する。

## エラー表示の読み方

`殻誤 0x…` と漢令の戻り値は、負の誤り番号を 64 ビットで表したもの。

| 値 | 意味 | 主な原因 |
|---|---|---|
| `0xfffffffffffffff2` | `-EFAULT`(14) | 窓外のアドレス、長さが上限（4 KiB）超過 |
| `0xffffffffffffffdc` | `-ENAMETOOLONG`(36) | 名前が 32 バイト超・パスが長すぎる・深すぎる |
| `0xfffffffffffffff3` | `-EACCES`(13) | 予約された章・器・志・権限 |
| `0xfffffffffffffffe` | `-ENOENT`(2) | 無い名前、目録の範囲外 |
| `0xffffffffffffffec` | `-ENOTDIR`(20) | 途中や移り先が章でない |
| `0xffffffffffffffef` | `-EEXIST`(17) | 作る・名替する先に既に篇がある |
| `0xfffffffffffffff7` | `-EBADF`(9) | 閉じた柄・不正な柄 |
| `0xfffffffffffffff0` | `-EBUSY`(16) | 開かれている篇・現在章は削れない |
| `0xffffffffffffffe4` | `-ENOSPC`(28) | 篇表・章が満杯 |
| `0xffffffffffffffda` | `-ENOSYS`(38) | 未知の漢令番号 |

## 漢令（システムコール）一覧

EL0 から `svc #0` で発行する。番号は x8 相当のフレーム位置、引数は x0〜x5（ABI は [abi-aarch64.md](abi-aarch64.md)）。

| 番号 | 名前 | 引数 | 動作 |
|---|---|---|---|
| 1 | 書出 | 址, 長 | 窓内のバッファをコンソールへ出す |
| 2 | 終行程 | 碼 | 行程を終える |
| 3 | 書数 | 値 | 値を 16 進で出力して改行（診断用） |
| 4 | 改行 | — | 改行を出力 |
| 5 | 譲渡 | — | 他の行程へ切り替える |
| 6 | 刻読 | — | タイマー刻数を返す |
| 7 | 開先取 | — | プリエンプションを有効にする |
| 8 | 待機 | 刻 | 指定した刻だけ眠る |
| 9 | 核棧址 | — | 自分の核棧上のフレームのアドレスを返す（診断用） |
| 10 | 読込 | 址, 数 | コンソール入力を窓内バッファへ読む（非阻塞） |
| 11 | 開 | 名址, 名長 | 典籍を開き、柄（3+番号）を返す |
| 12 | 閉 | 柄 | 柄を閉じる |
| 13 | 讀入 | 柄, 宛, 長 | 柄から読む（柄 0 はコンソール入力） |
| 14 | 柄書 | 柄, 元, 長 | 柄へ書く（柄 1/2 はコンソール出力） |
| 15 | 目録 | 序, 宛, 長 | 目録の `序` 番目の名前を窓内バッファへ写し、名前の長さを返す |
| 16 | 創 | 名址, 名長 | 典籍を作る。あれば内容を空にする。成功で 0 |
| 17 | 生行程 | 名址, 名長, 引址, 引長 | 名前の漢像から子行程を作り、子の識を返す。失敗は `-ENOENT`・`-ENOEXEC`・`-EAGAIN`・`-ENOMEM` |
| 18 | 待行程 | 識, 状址 | 子（識、`-1`=任意）の終了を待ち、終了コードを `状址` に書いて子の識を返す。子が無ければ `-ECHILD` |
| 21 | 識別 | なし | 呼出側の識 |
| 24 | 削 | 名址, 名長 | 典籍を削る。成功で 0、無い名前は `-ENOENT`、開かれていれば `-EBUSY`（19〜20・22〜23 は [行程の設計](design-process-exec.md) で予約済み） |
| 25 | 名替 | 旧址, 旧長, 新址, 新長 | 篇の名と親の章を替える。新が既にあれば `-EEXIST`、予約章は `-EACCES` |
| 28 | 章作 | 名址, 名長 | 章を作る。成功で 0 |
| 31 | 頁残 | なし | 頁池の空きページ数（診断） |
| 32 | 章移 | 名址, 名長 | 現在章を変える。章でなければ `-ENOTDIR` |
| 33 | 章名 | 宛, 長 | 現在章の絶対パスを宛へ写し、全体の長さを返す |

アドレス引数は民の窓（仮想 `0x40600000`〜`0x40800000`）内に限る。窓外・長さ超過は `-EFAULT`。
柄 `0`/`1`/`2` はコンソール、`3` 以降が典籍。
