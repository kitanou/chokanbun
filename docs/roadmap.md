# 開発ロードマップ

## M0: 言語最小仕様
- 整数、ポインタ、関数、文字列、MMIO、無標準ライブラリ
- 字句/構文解析、型検査、LLVM IR出力

## M1: 世界安寧
- QEMU virt/AArch64で起動
- 機械漢文ソースから生成したコードでPL011 UARTに「世界安寧」を表示
- GDBで再現可能なテストとビルド手順

## M2: カーネル基盤
- 例外ベクタ、タイマー、物理メモリ、MMU

## M3: 行程
- スケジューラ、EL0実行、SVC、アドレス空間

## M4: 文件とシェル
- VFS、簡易RAMファイルシステム、漢文シェル

## M5: POSIX互換サブセット
- read/write/open/close、exec/wait/pipe、forkなどを段階的に検証

## 品質ゲート
各マイルストーンに自動ビルド、QEMUテスト、再現手順、ログを付ける。
