# BTRON3 OS 仕様編 3.5 トレーマネージャ

> 親Issue: [#42](https://github.com/kitanou/chokanbun/issues/42) / 基準: os_spec/shell/tray.html
> 実装: `user/btron/tray.mkn`。試験: `描試` の `描試二十三`（11 項目）。

## 1. 概要

トレーは「切り取る」「写し取る」「貼り込む」「取り込む」で使うスタック状の容器（既定で 10 個。最低 5 個を保証）。先頭が最後に格納したデータで、データ位置は先頭を 1 とする。空でなければ「選択状態」のデータが必ず 1 つある。「一時トレー」はドラッグ用で、システムに 1 つ、常に開いていて、データを 1 つだけ持つ。名称は付けられない。

1 つのデータは `TRAYREC` の列（`W id`、`W len`、`B *dt` の 16 B）。`id` は TAD のセグメント ID（0x80〜0xFD）か `TR_VOBJ`(1)・`TR_TEXT`(2)・`TR_FIG`(3)。分割した記録には `TR_CONT`(0x4000) を付ける。マネージャは中身を見ない。

## 2. 関数（10/10）

| 関数 | 実装 | 誤り |
|---|---|---|
| `topn_tra()` | 開く（開いていれば何もしない）。空で始まる | — |
| `tcls_tra()` | 閉じて内容を捨てる | `EX_TRAY` |
| `tpsh_dat(data, nrec, name)` | 先頭へ格納して選択。名称は先頭 12 TC。溢れると最後が消える。格納したレコード数を返す | `EX_TRAY` `EX_PAR` `EX_ADR` `EX_NOSPC` |
| `tpop_dat(data, size, a_size, rec, name)` | 選択データを取り出す（消さない）。rec < 0 全体、= 0 ヘッダだけ、> 0 そのレコードの本体 | `EX_TRAY` `EX_ADR` `EX_PAR` |
| `tdel_dat()` | 選択データを消し、直後（無ければ直前）を選ぶ。新しい選択位置を返す。空なら 0 | `EX_TRAY` |
| `tsel_dat(pos)` | pos を選択。範囲外は末尾。pos ≦ 0 は変えず現在位置を返す。空なら 0 | `EX_TRAY` |
| `tmov_dat(pos)` | 選択データを pos へ動かす（pos ≦ 1 は先頭、数より大きければ末尾）。空なら 0 | `EX_TRAY` |
| `tget_sts(size, rsize)` | データ数を返し、総バイト数と残りを NULL でなければ設定 | `EX_TRAY` `EX_ADR` |
| `tset_dat(data, nrec)` | 一時トレーに置き換えて格納。nrec = 0 で空に | `EX_PAR` `EX_ADR` `EX_NOSPC` |
| `tget_dat(data, size, a_size, rec)` | 一時トレーから取り出す（残る）。`tpop_dat` と同じ rec の意味 | `EX_ADR` `EX_PAR` |

取り出しの戻り値は、rec ≦ 0 のとき総レコード数、rec > 0 のときそのレコードの `id`。空なら `*a_size` = 0・戻り値 0。存在しない rec は `EX_PAR` で `*a_size` = 0。`data` が NULL なら何も書かず、`*a_size` にその方式で書くはずの大きさを返す。

`er.mkn` に `EX_TRAY`(0x18) を足した（名称のみで数値の規定は無い。`EX_*` の通し番号の続き）。

## 3. 選んだ設計（原文に無い所）

- 利用者ごとの区別は無いので、トレーは全行程で 1 つ（データマネージャと同じ）。共有画面の塊の後ろ 0x63FC0000 に表を置く（排他は未対応）。`data.mkn` の置き場は 448 KiB から 192 KiB に縮めた。
- 管理表 4 KiB と、20 KiB の槽が 11 個（スタック 10、一時 1）。1 つのデータは [TRAYREC の列][本体] を 1 つの槽に写して持つので、**1 つのデータは 20 KiB まで**（超えると `EX_NOSPC`）。`tget_sts` の総バイト数は列も含めた格納量、残りは 10 槽分からの差。
- 取り出しのバッファが足りないとき、`EX_PAR` を返し、収まるレコードの見出し・本体だけを書く（原文は「size 分だけ格納」）。指定レコードのときは先頭から size バイト。
- 全体取り出しでは `dt` が出力バッファ内の本体を指す。ヘッダ取り出しでは 0。
- 名称は 12 TC まで。取り出し側は 13 TC（26 B）を書く。一時トレーに名称は無い。
- `tpsh_dat` の検査順は、開いているか → `nrec` → `data`・`name` の窓 → 各レコード（`id` ≦ 0・`len` < 0 は `EX_PAR`、本体が窓外は `EX_ADR`）→ 槽に収まるか。

## 4. 未対応

- 利用者ごとのトレー、利用者のセッション終了での自動クローズ。
- TAD の中身（`TR_VOBJREC`・`TR_CONT` の整合）の検査、20 KiB を超えるデータ。
- 切り取り・貼り込みの利用側（漢殻・アプリ側の操作）。
