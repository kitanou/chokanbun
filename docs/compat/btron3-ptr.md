# BTRON3 OS 仕様編 2.6 ポインタ制御関数

> 親Issue: [#42](https://github.com/kitanou/chokanbun/issues/42) / 基準: os_spec/dp/pointer_func.html
> 実装: `user/btron/ptr.mkn`。試験: `描試` の `描試二十六`（4 項目）。

## 関数（6/6）

| 関数 | 実装 | 誤り |
|---|---|---|
| `gini_ptr()` | 状態を既定に戻す（消去要求 0、標準形 0、前景 0・背景 0xFF、追従、大きさ 24）。位置は変えない | なし |
| `gdsp_ptr(req)` | `req` = 0 で消去要求数を +1、> 0 で −1（0 まで）、< 0 で 0 に戻す。消去要求数を返す | なし |
| `gset_ptr(style, img, fgcol, bgcol)` | `style` < 0 は `img`（PTRIMG、1032 B）を保持、≥ 0 は標準形（0・1・2・15）。色が負なら既定 | `EG_ADR` `EG_PAR`（大きさ 0 または 64 超・縦横不一致、未知の形） |
| `gmov_ptr(pos)` | 非追従のときだけ位置を変える。追従状態（0/1）を返す | `EG_PAR`（320×240 の外） |
| `gmot_ptr(sts)` | 0 で非追従、非 0 で追従 | なし |
| `gget_ptr(sts, img)` | PTRSTS（28 B）と画像を返し、関数値は大きさ。NULL は書かない | `EG_ADR` |

## 選んだ設計

- **画面にポインタを描かない**。状態を持って問い合わせに答えるだけ（描画と入力装置への追従は未対応）。状態は共有画面の塊の後ろ 0x63FFDE00。
- 標準形は原文に載っている `PS_SELECT`=0・`PS_MODIFY`=1・`PS_MOVE`=2・`PS_MENU`=15 だけを受ける。標準形の `gget_ptr` の画像は 24×24 の大きさだけ返しビットは 0。
- `gdsp_ptr` の `req` の不等号は原文で欠けていたので、説明文から 0＝消去・正＝表示・負＝強制表示とした。`P_SIZE` の式（512）と本文の 32/96/128 B は食い違うので、PTRIMG は 512+512 B の固定長にした。
