> 出典: BTRON3 仕様書 Ver. 3.20.00 第2編 第3章 3.4（`os_spec/shell/panel.html`、12 関数）。更新: 2026-10-31。
> 状況: **12/12 関数を実装（§6・§7。`popn_pnl`・`pact_err` は常に `EX_DNUM`）**。原文は漢字切替列が壊れた形で取得され、手作業で復号した。**(推定)** と付けた箇所は読みが確定していない。図 96〜101 は画像で未確認。本文は転載せず独自の言い回しで要約する。

## 1. 位置づけ

- ダイアログパネル（設定・確認を求め、終わるまで消えない）の生成・削除・操作と、システムメッセージパネルの表示を担う。
- パネルは入れ子にでき、新しいパネルが手前に出て入力状態も移る。閉じると、開く前に入力状態だったウィンドウへ戻る（`EV_SWITCH`・`W_SWITCH`）。
- パネル ID（`PNID`、正の `W`）は行程ローカル。行程が終わると、その行程のパネルも自動で消える。
- 操作は 2 通り: (1) アプリが `wget_evt`（`NOMSG` 指定。他の窓へ切り替わらないようにする）でイベントを自分で処理する。(2) 標準動作関数 `pact_pnl` を繰り返し呼ぶ。イベントによっては (1) が必要。
- 各パネルは独立した描画環境を持つ。座標はパネル表示領域の左上（境界線を含む）が (0,0)。フレーム長方形は境界線を含む全体、表示長方形は内枠の内側の作業領域で、その左上は (0,0) ではない。
- システムメッセージパネルは起動時に自動生成される、画面の固定位置の領域（他の窓・パネルと重ならない）。全面モードでも 1 つ見えるが操作はできない。メッセージのほか、メタキー状態に応じた言語モード・入力補助モード・現在時刻を出す。

## 2. データ型と定数

| 名 | 内容 |
|---|---|
| `PNID` | `W`。パネル ID |
| `PANEL` | `oframe`（外枠の属性 UW）・`iframe`（内枠の属性 UW）・`bgpat`（背景 `PAT_DAT` の番号、0 は既定）・`r`（外枠を含む全体の絶対座標）・`defsw`（既定スイッチの項目番号、なければ 0）・`nitem`・`item`（`PNL_ITEM` の配列、項目番号は 1〜`nitem`） |
| `PNL_ITEM` | `itype`（種別）・`info`（付加情報。オールタネートスイッチではグループの所属ビット。0 なら独立、グループは最大 32、複数所属可。他の種別では無視）・`ir`（パネル左上を原点とする表示領域。項目はここへクリップ、空なら非表示。パーツでは定義内の表示領域の左上を合わせ、右下は使わない）・`desc`（内部ディスクリプタ: パーツは パーツ ID、データ番号定義は共有メモリのアクセスキー、他は 0）・`dnum`（データボックスの定義を使うときの番号、正）・`ptr`（直接メモリ上の定義。このとき `dnum` は 0。`dnum` が 0 でなければ `ptr` は無視 (推定)） |

項目種別 `itype`:

| 値 | 名 | 意味 |
|---|---|---|
| 0 | `NULL_ITEM` | 空。表示せず、`ACT_ITEM` と併せて領域内の PD 押下の検出に使う |
| 1 | `PTR_ITEM` | ポインタイメージ |
| 2 | `PICT_ITEM` | ピクトグラム |
| 3 | `PAT_ITEM` | パターン |
| 4 | `BMAP_ITEM` | ビットマップ |
| 5 | `FIG_ITEM`（定義コード。表の記述は「予約」で不一致） | 要確認 |
| 6 | `TEXT_ITEM` | 文字列（定義コードの注記は 1 行） |
| 7 | `PARTS_ITEM` | コントロールパーツ（3.3） |
| 0x80 | `ACT_ITEM` | 動作項目。PD 押下をアプリへ通知。パーツ以外と OR する |
| 0x40 | `BLT_TEXT` | 定義コードにのみあり、本文に説明なし |
| 0x20 | `ATR_TEXT` | 属性付き文字列（`TEXT_ITEM` と OR）。TAD の付加記号 4 種（フォント・フォント属性・文字サイズ・文字カラー）を含められる。指定なしで登録すると表示は保証されない。表示領域の上端に揃える |

パネルの見た目: 外枠（幅・パターン。影は幅に含まない）・内枠（幅・パターン）・両者の間隔・背景。種類は通常・警告・重大警告の 3 つ。通常は保存・確認などのモーメンタリスイッチが 1 つあり、`defsw` で指定して太枠で強調する。

## 3. 関数（12）

| 関数 | 要点 | エラー |
|---|---|---|
| `pcre_pnl(PANEL*, PNT*)` | 定義からパネルを作り表示。`p` が NULL なら定義内の位置。`p->x`・`p->y` が 0x8000 で水平・垂直中央。定義は生成後も参照されるので保持する。`oframe`・`iframe`・`bgpat` の番号不正は既定、`defsw` の不正は既定なし。戻り値は PNID | `EX_ADR` `EX_NOSPC` `EX_PAR` `EX_SAVE`（入れ子のイメージ保存領域不足） |
| `popn_pnl(dnum, PNT*)` | データボックスの `PANEL_DATA` から生成 | `EX_ADR` `EX_DNUM` `EX_NOSPC` `EX_PAR` `EX_SAVE` |
| `pdel_pnl(pnid)` | 削除して表示を消す。持つパーツも消える | `EX_PNID`（無い、または最前面でない (一部推定)） |
| `pact_pnl(pnid, EVENT*, itemno*)` | 標準動作を 1 歩進め、結果のイベントと項目番号を返す。既定スイッチが押されて完了するまで繰り返し呼ぶ。入力状態のボタンが無ければ最小番号のボタンを入力状態にする。ボタン型パーツの `cact_par` の戻り値で分岐し、タブ・入力終了・改行などで終わると `cact_par` の値を返し `*ev` は `EV_NULL`。`ACT_ITEM` の項目で PD 押下があるとその時点で戻り、`*ev` は `EV_BUTDWN`・値 0。ボタン／キー以外のイベントとメニュー指定（`P_MENU` 0x6010、その他 `P_EVENT` 0x6020）は入力状態のボタン番号とイベントを返す。`EV_REQUEST` の `W_REDISP` では呼び出し側が再描画する | `EX_ADR` `EX_PNID` |
| `pget_itm(pnid, itemno, item*)` | 項目の定義を取得。`desc` は登録パーツ ID・アクセスキー・0、同じ値が関数値。`item` が NULL のときは判読不能 | `EX_ADR` `EX_PAR` `EX_PNID` |
| `pset_itm(pnid, itemno, item*)` | 項目の定義を変えて再表示。`item` が NULL なら再表示のみ。`itemno` が -1 かつ NULL で全項目を再表示 | 原文に節なし |
| `psel_box(pnid, itemno)` | ボタン型項目を入力状態にし、直前の入力状態の番号を返す。0 は状態を変えず現在の番号（なければ 0）を返す。説明の末尾は欠落 | `EX_PAR` `EX_PNID` |
| `pget_gid(pnid)` | パネルの描画環境 ID。直接描くときは設定を変えて描き、元へ戻す。変えたまま操作した場合の動作は保証されない | `EX_PNID` |
| `pact_err(kind, arg1, arg2, arg3)` | 標準エラーパネル（`PANEL_DATA` の番号 `kind`。負なら `-kind`、絶対値は 1000 未満 (推定)）を表示して処理。先頭 3 項目までが文字列項目なら `arg1`〜`arg3` で順に置換。戻り値は押されたモーメンタリ項目番号 − 既定スイッチ番号。既定スイッチと、そこから連続する n 個のモーメンタリ項目が必須。保存・復元はしないので描画データは呼び出し側が用意 | `EX_ADR` `EX_PAR`（`kind` 不正・未登録・既定スイッチ無し・既定番号より小さい番号に `PARTS_ITEM`）`EX_SAVE` |
| `pdsp_msg(TC*)` | システムメッセージパネルの表示を消して新しいメッセージを出す。NULL は消去のみ。既定フォント・色、はみ出しはクリップ。戻り値の詳細は欠落 | `EX_ADR` |
| `pdsp_tim(UW stat)` | メタキー状態に応じた言語モード・入力補助モードと現在時刻を表示・更新。ウィンドウマネージャが周期的に呼ぶ想定 (推定) | 原文に節なし（空） |
| `pact_msg(WEVENT*)` | システムメッセージパネルのイベントを処理して更新。ウィンドウマネージャが自動で呼ぶので通常のアプリは呼ばない | `EX_ADR` |

エラーはすべて `EX_*`（`ER_*` は出てこない）。

## 6. 実装の状況（最小実装）

`user/btron/panel.mkn`（QEMU virt 上、`描試` 6 項目）。実装は `pcre_pnl`・`pdel_pnl`・`pget_gid`・`pact_pnl`・`pget_itm`・`pset_itm` の 6 関数で、項目は `NULL_ITEM`・`TEXT_ITEM`（どちらも `ACT_ITEM` を重ねられる）。表は共有画面の塊の +0x100000 で入れ子は 4 段まで、下の画面の退避は +0x110000 から 1 パネル 16384 ピクセルまで（超えると `EX_SAVE`）。`EX_PNID`（0xFFFE0010）・`EX_SAVE`（0xFFFE0011）を `er.mkn` に追加した。原文が取得できていない部分は次のとおり選んだ（ファイル先頭にも同じ記録がある）。

- **構造体**: `PANEL` は 40 B（`oframe`・`iframe`・`bgpat` が各 4 B、`r` が RECT 8 B、`defsw`・`nitem` が各 4 B、`item` が 8 B）。`PNL_ITEM` は 32 B（`itype`・`info` が各 4 B、`ir` が RECT 8 B、`desc`・`dnum` が各 4 B、`ptr` が 8 B）。`TEXT_ITEM` の `ptr` は TC の文字列（NUL 終わり、64 字まで）。
- **形状**: 黒の 2 ピクセルの外枠と白地、右と下に 2 ピクセルの黒い影。描画環境は左上が (0,0)、フレーム長方形は本体全体、表示長方形は外枠の内側。項目は `ir` を白で塗って文字を左上に置き `ir` にクリップする。位置 `p` の x・y が 0x8000 なら中央、画面からはみ出すときは中へ寄せる。
- **操作**: `pact_pnl` は `ACT_ITEM` の `ir` の中の `EV_BUTDWN` を `ev`・`itemno` で返して 0、`ir` の外の押下は捨て、他のイベントは `P_EVENT` で返し、イベントが無いまま回数が尽きると `EV_NULL`。`pdel_pnl` は最前面のパネルだけ消せる。

【未対応】§7 の残りを参照。

## 7. 実装の状況（残りの 6 関数）

`psel_box`・`popn_pnl`・`pact_err`・`pdsp_msg`・`pdsp_tim`・`pact_msg` を足して 12/12 関数（`描試` 6 項目を足して 12 項目）。`panel.mkn` の先頭にも同じ記録がある。

- **`psel_box`**: ボタン型の項目（`ACT_ITEM` を持つ項目）を入力状態にして、直前の番号（無ければ 0）を返す。0 は変えずに今の番号を返す。ボタン型でない・範囲外は `EX_PAR`。入力状態の項目は `ir` の縁に黒い 1 ピクセルの枠で示す（文字は `ir` の左上なので重なる）。`pact_pnl` は入力状態のボタンが無いと、最小番号のボタンを入力状態にする。
- **`popn_pnl`・`pact_err`**: `PANEL_DATA` を持つデータマネージャ（3.6）が無いので、引数の検査（`EX_ADR`・`EX_PAR`）のあと常に `EX_DNUM`。**実際には何も出せない。** `pact_err` の `kind` は絶対値が 1〜999 でなければ `EX_PAR`。
- **システムメッセージパネル**: 画面下端の高さ 16 ピクセルの帯（灰色の地、上に黒線）。起動時の自動生成はせず、`pdsp_msg`・`pdsp_tim` で描く。メッセージは共有画面の塊の `板表` + 0x50000 に持つ。
- **`pdsp_msg`**: 帯の左に文字を出して字数（127 まで）を返す。NULL は消すだけ。**`pdsp_tim`**: 帯の右に `stat` の表示（ビット 0 が 1 で `J`・0 で `E`、ビット 1 が 1 で `A`・0 で `-`、推定）と現在時刻 `HH:MM`（`get_tod`）を出す。**`pact_msg`**: 帯の中の PD の押下・離し（絶対座標）なら描き直して `ev` を `EV_NULL` にし 1 を返す。関係無いイベントは 0。

【未対応】`PARTS_ITEM`・図形系の項目・`ATR_TEXT`・`BLT_TEXT`・`dnum` の項目（どれも `EX_PAR`）、`defsw` の太枠、入力状態の移動（`EV_SWITCH`・`W_SWITCH`）、枠・背景・パネルの種類（警告）、パネルへの所属パーツ、登録行程の終了での自動削除、他のウィンドウとの重なりの再表示、システムメッセージパネルの自動生成と全面モード。
