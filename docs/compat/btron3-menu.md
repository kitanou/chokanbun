## 1. 位置づけ

- HMI の一部。表示形状の詳細は実装依存。メニュー ID（`MNID`、正の `W`）は行程ローカルで、他行程へ渡して操作できない。登録した行程が終わると自動削除される。
- **標準メニュー**: 最初に出るメインメニューと、項目を選んで開く 2 階層目のサブメニュー。サブメニューを開く親項目と、最終指示を与える子項目（末端項目）がある。1 階層だけのポップアップや、サブメニューを持たないメイン項目も可。項目が画面に収まらないときは左右 2 分割。選択中の項目は反転。サブメニューは反転中のメイン項目の右（画面端では左）に出る。
- **汎用メニュー**: 1 階層のポップアップ。標準メニューのサブメニューに似るが、項目の配置を座標で指定する。
- 項目の種類: 状態項目（インジケータあり）・動作項目（インジケータなし）・不能項目（灰色で選べない。親が不能なら子は出ない）・強調項目（下線）・区切り線・図形項目（`PTR`/`PICT`/`PAT`/`BMAP` の図形データ）。
- 表示位置属性（全メニュー共通）: `M_FIXPOS`（メインの 2 番目の項目をポインタ直下に置く）か `M_LASTPOS`（最後に使ったメイン項目）。
- 操作: メニューボタン、または [命令] キー + PD 押下でメインメニューを出す。親項目の上で一定時間止まるとサブメニューが開く（時間は `mchg_dtm`）。子項目を選ぶと選択されて消える。[命令] + 文字キーは `mfnd_key` で項目を探す（キーコードは項目ごとに最大 15）。経路の途中に別の項目がある場合の規定は原文が欠落。

## 2. データ型と定数

| 名 | 内容 |
|---|---|
| `MENUDISP` | 表示属性。`m_frame`・`s_frame`（枠の幅とパターン、幅は最大 8）・`m_bgpat`・`s_bgpat`・`s_indpat`（`PAT_DATA` の番号、0 は既定）・`m_chcol`・`s_chcol`・`s_keycol`（`COLOR`、負は既定） |
| `MENUITEM` | `inact`（不能フラグ）・`select`（選択フラグ）・`desc`（内部用。設定時は無視）・`dnum`（項目リストの `TEXT_DATA` 番号。正なら `ptr` は無視）・`ptr`（項目リスト。NULL は子なし）。フラグのビット 0〜31 が項目 0〜31 に対応し、`mchg_atr` で 32〜127 も扱う |
| `GMENU` | `frame`・`bgpat`・`indpat`・`chcol`・`area`（全体の領域）・`inact`・`select`・`desc`・`dnum`・`ptr`・`nitem`（最大 128）・`r[32]`（項目ごとの領域）。128 と 32 の関係は曖昧（32 を超えると 32 として登録 (推定)） |
| 項目リスト | 最大 128 項目。先頭が親項目、残りが子項目。番号は定義順で、親が 0 始まり・子が 1 始まり (推定) |

属性コード（項目リスト内の 16 ビット単位の指定）:

| 名 | 値 | 意味 |
|---|---|---|
| `MC_LINE` | 0x1004 | 区切り線 |
| `MC_KEY` / `MC_KEY1`〜`MC_KEY15` | 0x10f0 / 0x1010〜0x10f0 | キーコード数のマスクと 1〜15（0x1000 + 0x10 × n） |
| `MC_IND` | 0x1100 | 0 動作項目、1 状態項目 |
| `MC_SEL` | 0x1200 | インジケータ OFF／ON |
| `MC_FIG`・`MC_ATTR`・`MC_EMPHAS`・`MC_INACT` | 数値の記載なし | 文字／図形、標準／指定属性、通常／強調、正常／不能 |

- 図形項目: 上位 16 ビットが `TTTT DDDD DDDD DDDD`（T は 0 `PTR`・1 `PICT`・2 `PAT`・3 `BMAP`、D は番号で 0 は非表示）、下位に横幅の文字数 1〜16。
- 指定属性（`MC_ATTR` = 1）の文字項目: 直後に 12 バイト（文字色・フォントクラス・フォント属性・フォントサイズ。サイズが 0 以下なら既定、標準より大きい指定は不可）。
- `mchg_atr` の `mode`: `M_STAT` 0・`M_SEL` 1・`M_INACT` 2・`M_NOSEL` 4・`M_ACT` 8。表示位置属性: `M_LASTPOS` 0・`M_FIXPOS` 2。

## 3. 関数（15）

共通: 戻り値は正常で 0 以上、エラーで負。エラーはすべて `EX_*`。

| 関数 | 要点 | エラー |
|---|---|---|
| `mcre_men(nitem, MENUITEM*, MENUDISP*)` | 親項目 `nitem` 個の標準メニューを登録。`attr` が NULL なら既定。内容は登録後も参照されるので保持する | `EX_ADR` `EX_NOSPC` `EX_PAR` |
| `mopn_men(dnum)` | `MENU_DATA` から登録 | `EX_DNUM` `EX_NOSPC` `EX_PAR` |
| `mdel_men(mid)` | 削除 | `EX_MID`（無い、標準メニューでない） |
| `msel_men(mid, PNT pos)` | 絶対座標 `pos`（メニューボタンの押下位置）に出して選択操作。戻り値は選ばれた項目番号（1 始まり、無選択は 0）。取るイベントは `EV_BUTDWN`・`EV_BUTUP`・`EV_KEYDWN`・`EV_KEYUP`・`EV_AUTKEY`。ポインタ形状は変えない。画像の退避領域が取れない場合の記述は欠落 | `EX_MID` |
| `mfnd_key(mid, TC ch)` | [命令] と同時に押された文字 `ch` に対応するキーコードを持つ項目の番号。無ければ 0。キーコードの解釈（システムスクリプト）の説明は途中で切れる | `EX_MID` |
| `mget_itm(mid, pnum, MENUITEM*)` | 親項目 `pnum` の内容を取得 | `EX_ADR` `EX_MID` `EX_PAR` |
| `mset_itm(mid, pnum, MENUITEM*)` | 親項目の内容を設定。項目リストを直接書き換えたら必ずこれで再設定 | `EX_ADR` `EX_MID` `EX_PAR` `EX_DNUM` |
| `mchg_atr(mid, selnum, mode)` | 項目の不能・選択フラグを変更し、変更後の属性を返す（内容の一覧は欠落）。動作項目では `M_SEL`・`M_NOSEL` を無視し戻り値の選択は常に 0 | `EX_MID` `EX_PAR` |
| `mchg_dsp(MENUDISP*, posattr)` | 既定の表示属性と表示位置属性を変更。`attr` が NULL なら表示属性は不変、`posattr` が負なら位置属性は不変。戻り値は変更後の位置属性 | `EX_ADR` `EX_DNUM` |
| `mchg_dtm(time)` | サブメニューを出すまでの待ち時間（ミリ秒 (推定)）を変更し、変更前の値を返す。負なら変更しない | なし |
| `mcre_gmn(GMENU*)` | 汎用メニューを登録。不正な枠属性は既定 | `EX_ADR` `EX_NOSPC` `EX_PAR` |
| `mopn_gmn(dnum)` | `GMENU_DATA` から登録 | `EX_DNUM` `EX_NOSPC` `EX_PAR` |
| `mdel_gmn(mid)` | 削除 | `EX_MID` |
| `msel_gmn(mid, PNT pos)` | 汎用メニューの選択操作。戻り値は 1〜128、無選択は 0。イベントは `msel_men` と同じ | `EX_MID` |
| `mchg_gat(mid, num, mode)` | 汎用メニュー項目の属性変更（`mchg_atr` と同じ `mode`）。原文は「`MC_IND` = 0 なら `M_SEL` を無視」とするが、汎用メニューに `MC_IND` は無く文の流用と思われる (推定) | `EX_MID` `EX_PAR` |
