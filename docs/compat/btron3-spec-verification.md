## 2. 1.6 ファイル管理: 原文のモデル（要約）

- **ファイル**は実身、**リンク**は仮身に 1 対 1 に対応する。ディレクトリは無い。リンクは**ファイルの中のレコード**（固定リンク）として存在し、ネットワーク状の参照関係を作る。
- **ファイル名はファイル自身の管理情報**（最大 20 文字、変更可、重複可）。リンクは名前を持たない。パス名の各要素は「そのリンクが指すファイルの名前」で、同名は**出現順**（そのファイル内で、同じ名前のファイルを指すリンクの n 番目、0 始まり）で選ぶ。
- **リンクの構造**は `LINK` = {fs_name[20], f_id, atr1〜atr5}。**固定リンクは FS 名を持たない**（取り出すと所属 FS の名前が入る）。同じ FS の中の参照だけができる。
- **別の FS を指す**には、自分の FS に**リンクファイル**（独立したファイルで、`f_type` の種別が 0）を作り、それを指す固定リンクを置く（**間接リンク**）。リンクファイルは参照先の FS 名・ID・ファイル名・生成日時・デバイス所在名を持つ。FS 名で FS を特定し（接続名は無関係）、ID のファイルが名前・生成日時の**どちらかが**合い、かつリンクファイルでなければ参照先とみなす。2 段以上は不可。
- **参照数**: 通常ファイルの参照数 = そのファイルを指す**同一 FS 内の固定リンクの数**。**生成時は 0**、固定リンクを格納すると +1、削除で −1。リンクファイル経由は数えない。ルートは最初から 1 で消せない。削除できるのは**参照数 0 のファイルだけ**。リンクレコードを含むファイルの削除は `force` が要り、含んでいたリンクの先の参照数を −1 する（0 になっても先は消さない）。
- **浮動リンク**（`F_FLOAT`、既定）= 固定リンクとして格納**しない**動的なリンク。`cre_fil` を `F_FLOAT` で呼ぶと、ファイルを作るだけで**リンクレコードは作らない**（参照数 0、`lnk` は FS の指定と、結果の LINK の出力）。`F_FIX` なら親ファイル（`lnk`）の**最後**にリンクレコードを足し、参照数が 1 になる。`F_FILEID` は ID 指定。
- **パス名**: 絶対パスは `/` + **接続名**（`TC_FDLM` の後に接続名）で始まり、`≡`（`TC_FOWN`）は作業ファイルを指す特殊参照。それ以外は作業ファイルからの相対。要素は `名前` か `名前` `TC_FSEP` `出現順`。末尾の `/` は無視。パスをたどるには、途中の各ファイルの**実行／サーチ（E）権**が要る（対象自身の E は不要）。`get_lnk` は `path`=NULL で作業ファイル、戻り値は 0（通常ファイルのリンク）・1（リンクファイルのリンク）・2（`F_DIRECT` でリンクファイルの参照先のリンク）。
- **アクセス管理**: 所有者名は生成者が自動設定され**一切変更できない**。アクセス管理情報（モード・属性・パスワード）を変えられるのは**所有者だけ**。所有者が無い（先頭 1 字が 0）ファイルは、例外的に**レベル 0 のユーザ**が変えられる。FS のアクセス管理レベルが 0 の FS では**誰でも**所有者として変更でき、全ファイルが「所有者なし・グループなし・所有者モード 0・グループ 0・一般 0x0FFF」になる。レベル 0 のユーザは所有者の権利は持たないが、書込不可属性が無い限り全ファイルに RWE できる。`f_grpacc`/`f_pubacc` は R=ビット 11〜8、W=7〜4、E=3〜0 に**許可される最低（＝数が最大の）ユーザレベル**を持つ。削除の自体は特別な権利を要さないが、実際には削除するファイルを指す**固定リンクを含む全てのファイルに W が要る**。
- **FS の接続**: 起動時は FS が 1 つも接続されていない。`att_fls` で接続し、ルートのリンクが得られる。書込不可の接続（`FS_RONLY`）ではあらゆる変更が禁止。
- **レコード**: タイプ 0=リンク、1〜31=データ。リンクレコードのサイズは `LINK` の 52 B だが、ファイルの総バイト数には数えない（0 として数える）。現在レコードは**挿入・削除では変わらず番号が変わる**。オープンした fd と現在レコードは**子プロセスに継承されない**。

## 5. 修正の進め方（案）

食い違いは 1.6 のモデルに集中している（F1・F2・F6・F7・F10 が相互に絡む）。部分的に直すと整合が崩れるので、**1.6 のモデルを原文どおりに作り直す段階**として扱う。

1. **段階 M1（モデルの作り直し）**: ファイル名を見出しへ、参照数を原文どおり（生成時 0、固定リンクで +1）、`cre_fil` の `F_FLOAT`/`F_FIX`/`F_FILEID`、`del_fil` の意味、リンクレコードを `f_id`+属性だけにし FS 名を持たせない、パスの `/` 接続名と `≡`、`get_lnk` の 0/1/2、`chg_wrk(NULL)`。録試を新しいモデルで書き直す（既存の項目の多くはモデル前提で作ったため）。
2. **段階 M2（構造体と権限）**: `F_STATE`・`F_LOCATE`・`A_MODE`・`DA_MODE`、所有者と FS レベル 0 の特例、`chk_fil`・`chg_*` の権限、`chg_fnm`・`chg_ftm`。
3. **段階 M3（リンクファイル）**: 種別 0、`cre_lnk`・`gen_fil`・`lnk_sts`・`syn_lnk`・`get_nlk`、`ins_rec` の `ER_REC`、`fnd_lnk`。

### 6.2 段階 M3（リンクファイル、録試 94 項目）

- **表現**: 見出しの種別（`f_type` 上位 4 ビット）が 0 のファイルがリンクファイル。本体の頁に `F_LINK`（132 B）をそのまま持つ（`f_name`・`f_id`・`rf_ctime`・`fs_name`・`fs_locat`）。参照数は通常ファイルと同じ（固定リンクで +1）。リンクファイルの名前（パスの要素）は保持している `f_name`。
- **参照先の解決**（`録連先`）: `fs_name` の FS が接続されていること（なければ `ER_NOFS`）、`f_id` のファイルが存在しリンクファイルでないこと、名前**または**生成日時のどちらかが一致すること（でなければ `ER_NOEXS`）。接続名は無関係。二重の間接は参照先がリンクファイルなので `ER_NOEXS`。
- **自動的に参照先へ**: LINK を受ける操作は、リンクファイルの LINK を参照先の通常ファイルとして扱う（`録鎖読` が置き換える。`opn_fil`・`fil_sts`・`chk_fil`・`chg_*`・`chg_wrk` ほか）。**そうしないもの**: `del_fil`（リンクファイル自体を消す。参照先は消えない）、`lnk_sts`・`syn_lnk`、`chg_fnm`（リンクファイルは保持名と参照先の実際の名前の両方を替える）、`get_lnk`（F_DIRECT なし）、`cre_fil`/`cre_lnk` の FS／親の指定。
- **`get_lnk`**: 途中の要素がリンクファイルなら参照先へ入ってたどる。最後がリンクファイルなら、F_DIRECT なしは 1（リンクファイル自体）、F_DIRECT ありは 2（参照先。無ければ `ER_NOEXS`/`ER_NOFS`）。
- **`cre_lnk`**: `ref` の FS 名・ファイル名が空なら `ER_FNAME`、作る先と同じ FS を指すと `ER_PAR`。生成日時は実行時刻（`ref->f_ctime` は無視）。F_FLOAT は参照数 0、F_FIX は親の末尾に固定リンクを足して 1、F_FILEID は既存 ID で `ER_EXS`。成功は 0。
- **`gen_fil`**: レベル 0 の行程だけ（`ER_ACCES`）。`stat->f_type` の種別 0 でリンクファイル（`ref->f_ctime` を生成日時にする）、それ以外は通常ファイルで、アプリタイプ・属性・アクセスレベル・所有者・日時を `stat` のとおりに設定する。
- **`fnd_lnk`**: 向き 0〜5（原文どおり）と F_SFILE・F_SNAME・F_SATR1〜5・サブタイプ。見つからなければ `ER_REC`。**`fnd_rec` の向きは M4 で直す**（`fnd_lnk` だけ先に原文どおり）。
- **`lnk_sts`**・**`syn_lnk`**・**`get_nlk`**: 原文どおり（`ER_NOLNK`、同期状態 0〜3、ID の昇順）。漢令番号は 171・172・173、`gen_fil` は 151、`fnd_lnk` は 162。

**未了**: `gen_fil` のレベル 0 以外の `ER_ACCES` 試験（行程のレベルを上げると戻せないため子行程が要る）、リンクファイルの `fs_locat`（デバイス所在名）は保持するだけで照合に使わない、`opn_fil` の `ER_LIMIT` など。
