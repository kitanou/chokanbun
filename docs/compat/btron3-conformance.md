## 重要な注意

- 本書は **適合を主張しない**。「完全準拠」は、対象項目すべてが「適合確認済み」で未解決の非適合がない状態を指す（#42）。
- 第2編 第1章（カーネル）は [btron3-os.md](btron3-os.md) で照合済み（原文の文字化けによる要確認事項あり）。それ以外は **未調査**。「関連する既存実装」欄は照合の出発点であり、適合の根拠ではない。
- 仕様書本文は転載しない。要求は独自の言い回しで要約し、参照箇所（章・節・URL アンカー）を記す。
- B-right/V の補足・拡張は本書の対象外。別表（`btron3-bright-v.md`、未作成）で管理する。

## 状態の定義

| 状態 | 意味 |
|---|---|
| 未調査 | 要求と既存実装をまだ照合していない |
| 未実装 | 要求を把握したが実装がない |
| 部分適合 | 一部の条件のみ満たす |
| 実装済・未検証 | 実装はあるが適合試験が不足 |
| 適合確認済 | 要求・実装・試験結果を照合済み |
| 非適合／未対応 | 意図的な相違または未対応（理由を記録） |
