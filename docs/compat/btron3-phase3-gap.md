# BTRON3 Phase 3 の残り（完了の判定）

> 親Issue: [#42](https://github.com/kitanou/chokanbun/issues/42)。Phase 3 の 2 項目を完了とするための、残りの差の一覧と判定の基準。
> 照合の記録は [btron3-phase23.md](btron3-phase23.md)、関数ごとの実装と試験は [btron3-matrix.md](btron3-matrix.md)。作成: 2026-11-06。

Phase 3 の 2 項目:

- **項目 1**: 実身／仮身／虚身、仮身の表示・移動・複写・開閉、付箋管理を規定どおりに実装する。
- **項目 2**: 外部から観測可能な操作意味と API を仕様どおりにし、画面デザインの実装依存部分は区別する。

OS 仕様編の 495 関数にはすべて実装がある。残っているのは、(A) 原文が実装に任せている画面デザインと、(B) 外から見える操作の意味の差である。**(A) は区別して記録すれば項目 2 を妨げない。(B) が 1 つでも残れば未達とする。**

## A. 実装依存として区別するもの（画面デザイン）

原文に図しか無い、または「インプリメント依存」とあるもの。見た目は変えてよいが、操作の意味（戻り値・状態・イベント）は B の基準で扱う。

| 対象 | 今の決め方 | 置き場 |
|---|---|---|
| 仮身・付箋の枠・タイトル部・表示エリアの描き方 | タイトル部の高さは chsz、外周 1 画素の枠、色は COLOR の指定 | `omgrx.mkn` |
| 仮身操作・実身操作・ディスク操作・付箋操作メニューの項目名と並び | `Vobj` `Open` `Close` などの ASCII の TC | `omgrm.mkn` |
| 表示管理メニューの項目名 | 親項目 `Window` の下に主ウィンドウのタイトル | `wndx.mkn` |
| ウィンドウの枠・タイトルバー・影の形 | 黒の 2 画素の境界線、右と下に影 | `wnd.mkn` |
| 全面モードの見た目 | 枠・タイトルバー・影を描かない | `wnd.mkn` |
| 選択枠の線 | XOR、長方形は幅 W（既定 2） | `omgrs.mkn` |
| チラツキの間隔の分解能 | 呼ぶたびに入れ替え（間隔は覚えるだけ） | `omgrs.mkn` |

## B. 直す必要がある差（操作の意味）

### 項目 1 に効くもの

| # | 差 | 原文の規定 | 今の実装 | 必要なもの |
|---|---|---|---|---|
| B1 | 付箋の登録 | `oreg_vob` の vlnk = NULL は付箋。付箋には EX_VOBJ を返す関数が多い | 付箋は登録できず EX_PAR。vid は常に仮身として扱う | 登録簿の項に付箋の印、付箋セグメント（FUSENSEG）の扱い、各関数の EX_VOBJ |
| B2 | 仮身の表示の中身 | タイトルに実身名（と続柄）を描く。虚身・処理中など状態に応じた表示。V_NOFRAME は点線。r との共通部分だけを表示 | 文字を描かない。状態で表示が変わらない。V_NOFRAME は枠なし。r は検査だけ | 実身名の取得と文字の描画（`dpchr`）、状態ごとの表示、点線、切り抜き |
| B3 | 開いた仮身の表示エリア | V_DISPALL は既定アプリを M_DISPREQ で起動して描かせる。`otad_vob` は M_TADREQ | V_DISPALL は V_DISP と同じ。`otad_vob` は表示エリアの中身を含めない | 描画環境を行程の間で共有する仕組み（共有塊の上のメモリ描画環境を別の行程から gid で使う）。結果の受け渡し（`oend_req`）はある |
| B4 | 仮身要求イベント | 名前変更・続柄変更・虚身への移行と解除・新版などで、他のウィンドウの仮身へ再表示などを求めるイベントを送る | 送らない | 送り先（仮身が載るウィンドウの管理プロセス）の特定と、`wsnd_evt` 相当の送信 |
| B5 | パネル | 保存先指定・名前変更・パスワード入力・続柄変更・新版作成・デバイス接続・ディスク状態・ウィンドウ背景色変更・エラーの各パネル | 出さない（名前は引数のまま、NULL は EX_PAR、取り消しは返らない） | パネルマネージャ（3.4）とテキストボックス（3.3）でパネルを出し、選択の結果を返す |
| B6 | 仮身操作メニューの実行 | `oexe_vmn` は項目に応じて名前変更・続柄変更・表示属性などを行う | Name・Relation は何もしない（VM_NONE） | B5 のパネル |
| B7 | ウィンドウに載る仮身 | 仮身はウィンドウ（wid ≥ 0）にも登録できる | 描画環境（wid < 0）に載るものだけ | ウィンドウの描画環境を使った登録・表示・検索 |

### 項目 2 に効くもの

## 進め方と完了の判定

1. B1 付箋の登録 → B2 仮身の表示の中身 → B4 仮身要求イベント → B5・B6 パネル → C1〜C5 ウィンドウとメニューの細部 → B7 → B3（描画環境の共有。設計を先に書く）→ C6・C7。
2. 1 つずつ PR にし、各 PR で上の表の行を「済み」に変えて、試験の項目（`実試`・`描試` など）を書く。
3. B と C の行がすべて済み、A の各行が実装依存として [btron3-matrix.md](btron3-matrix.md) の該当関数に注記されたら、Phase 3 の 2 項目を完了として #42 にチェックを付ける。
