# BTRON3 OS 仕様編 3.7 テキスト入力プリミティブ

> 親Issue: [#42](https://github.com/kitanou/chokanbun/issues/42) / 基準: os_spec/shell/tip.html
> 実装: `user/btron/tip.mkn`。試験: `描試` の `描試二十四`（7 項目）。

## 1. 概要

テキスト入力プリミティブ（TIP）は、キー入力イベントを受けて確定文字列（と補助の未確定文字列・文節情報）を返すフィルター。アプリは「テキスト入力ポート」を開き、`TIPREC`（56 B）に状態を受ける。入力モード（かな・ローマ字 n 方式・nn 方式）とブリンク周期はグローバル。カレット表示の関数も含む。

## 2. 関数（8/8）

| 関数 | 実装 | 誤り |
|---|---|---|
| `ichg_mod(mode)` | 入力モード 0〜2 を設定し、変更前を返す。負で問い合わせ | `EX_PAR` |
| `ichg_lrn(kind, stat)` | 学習辞書が無いので常に不対応 | `EX_NOSPT` `EX_PAR`（kind = 0 または負） |
| `iopn_tip(tip, mode)` | **直接モード（`TIP_DIRMD`）だけ**開ける。ID を返し、`TIPREC` を 0 にしてバッファのポインタを入れる。ポートは 8 個まで | `EX_ADR` `EX_PAR` `EX_NOSPT`（変換モード）`EX_LIMIT` |
| `icls_tip(tipid)` | 閉じる | `EX_TID` |
| `iput_key(tipid, evt)` | `EV_KEYDWN`・`EV_AUTKEY` の文字（`EVDATA.key.code`、イベントの +14）を 1 文節の確定文字列にして `TIP_OUT` を返す | `EX_TID` `EX_ADR` `EX_PAR` `EX_KEY`（コード 0）`EX_CKEY`（機能キー = 0xFE00 以上） |
| `iput_str(tipid, str)` | 直接モードでは使えない（原文のとおり） | `EX_TID` `EX_NOSPT` |
| `ichg_blk(intvl)` | ブリンク周期（ms）を設定し、変更前を返す。負で問い合わせ、0 でブリンクしない。既定 500 | — |
| `idsp_car(car, mode)` | 0 消去、> 0 表示、< 0 ブリンク。`car->sts` を更新。描けない（`EG_GID` など）ときは `sts` を変えずに誤りを返す | `EX_ADR` |

`er.mkn` に `EX_NOSPT`(0x19)・`EX_KEY`(0x1A)・`EX_CKEY`(0x1B)・`EX_TID`(0x1C) を足した。

## 3. 選んだ設計（原文に無い所）

- 辞書も変換器も無いので、変換モード（`TIP_CNVMD`、値 0 を含む）でのオープンは `EX_NOSPT`（原文が「サポートしない変換モード」として認める誤り）。`iopn_tip(tip, TIP_DIRMD)` だけが成功する。
- 直接モードのキー入力: 呼ぶたびに、前に確定した文節を捨て、新しい 1 文字を `n_out = n_cl = 1`・`cnv = in` = その文字・`cl_cnv = cl_in = {0, 1}`・`update = caret = clause = 0`・`n_roman = 0` にする。文字コードの正当性は 0 かどうかだけ見る。
- 表は共有画面の塊の後ろ 0x63FF8000（グローバル 16 B + 0x800 B のポート 8 個）。ポートはオープンしたプロセスにだけ有効で、他のプロセスの `tipid` は `EX_TID`。プロセス終了での自動削除は未対応。
- カレットは描画環境 `gid` に **白のパターンを XOR** で描く（全ビットが立つので、どのピクセル値も反転し、同じ描画で消える）。横書き（`kind` の D = 0）は幅 1・高さ `height` の縦棒、縦書き（D = 1）は高さ 1・長さ `height` の横棒。`height` ≦ 0 のときは 3×3 の点。カラーは使わない。
- ブリンクは、最後に反転した時刻（グローバル）から周期が過ぎていれば反転する（時刻は `get_etm`）。カレットごとの記録は持たない。

## 4. 未対応

- かな漢字変換、ローマ字かな変換、学習辞書、文節操作の機能キー。
- 複数のカレットを独立にブリンクさせること、色の指定。
- プロセス終了でのポートの自動削除。
