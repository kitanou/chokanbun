# 機械漢文システム言語 v0.1 — 規範仕様（M0凍結）

状態: **v0.1 実装・検証済み**（M0 受入条件 §10 を `tests/lang/` と `make test` で検証）。
本書が規範で、コンパイラ（`src/`）はこれに従う。仕様と実装の食い違いは、テストで固定した上でどちらかを直す。

## 1. 設計原則
- ソースはUTF-8。ソースファイルの拡張子は **`.mkn`**（`@取込` で取り込む部品、展開後のソースを含む。`.txt` は使わない）。コンパイラは拡張子を検査しないが、`make test` が `kernel/`・`user/`・`tests/`・`src/` に `.txt` のソースが無いことを確かめる。識別子・キーワードは漢字を基本とし、文法は機械的に一意に解析可能とする。
- OSのカーネル・ドライバを同一言語で実装する。実行時は通常の機械語・バイナリ構造。
- 漢殻（シェル）文法は別言語。NF/SCF/SeCFの自然言語圧縮表現はコンパイラIRと別物。
- M0はfreestanding、GCなし、例外なし、暗黙の動的確保なし、暗黙の整数変換なし。

## 2. 字句規則
- Unicode NFCへ正規化した後にトークン化する。NFKCは適用しない。正規化前の位置を診断用に保存する。
- 空白・改行は区切り（文字列内を除く）。インデントは構文的意味を持たない。
- 識別子は `「` と `」` で囲む。内部は1文字以上のUnicodeスカラー列で、`」` と改行は使用不可。識別子比較はNFC後の完全一致。予約語は識別子の外側でのみ有効。
- 識別子の内部には漢字のほか ASCII 英字・数字・`_`・`.` を使用できる。ASCII は `記號「ascii_symbol」`（§7）で外部リンカシンボル名を指定するため、`.` は `節「.text.boot」` のセクション名を書くために必要である。空白は使えない。
- 文字列は `『` と `』` で囲む。エスケープは `\n`, `\r`, `\t`, `\\`, `\』`、`\u{HEX}`。その他はエラー。
- 数値はASCIIの10進整数または `0x` + ASCII16進。負数は単項 `負`。数値リテラルは使用文脈の整数型に適合しなければ `E0010`（例: `無符八` への `300`、`有符八` への `128`）。64 ビットに収まらないリテラルも `E0010`。
- 型が文脈で決まらない整数リテラルは `有符六四` として扱う（リテラル同士の演算 `1 加 2` など）。他の整数型の変数と組み合わせるときは、その型に適合する。
- 行コメントは `註` から行末まで。複数文を同じ行に置く場合は空白で区切る。M0では文終端を予約語で識別する。
- 漢字の簡繁字は同一視しない（例: 讀と読は別トークン）。

## 3. 型
- `無符八`, `無符十六`, `無符三二`, `無符六四`; `有符八`, `有符十六`, `有符三二`, `有符六四`。
- `真偽`（真/偽）、`無`（戻り値なし）、`指標〈型〉`、`列陣〈型,長〉`、`構「名」...終構`。
- ポインタ幅64bit。nullは `空`。整数とポインタの暗黙変換は禁止。
- `別名「名」為 型` による型別名。構造体の配置は宣言順、C ABI互換レイアウト。自然アラインメント、パディングあり。packedはM0対象外。
- 符号付き整数の加減乗は2の補数でwrap、除算0はtrap、シフト量がbit幅以上はtrap。整数オーバーフローを最適化の未定義動作にしない。
- 型不一致、未初期化値の読み出し、配列範囲外の定数アクセスはコンパイルエラー。動的境界検査はM0では保証しない。
- `設` は必ず初期値を持つので、未初期化値の読み出しは自己参照 `設「甲」之無符六四 為 甲` でのみ生じ、`E0005` で拒否する。

## 4. 文法（規範的なEBNF）
`tests/lang/ok/` の golden テストが、この文法のすべての構文を解析木で固定する。
```ebnf
module      = { declaration } ;
declaration = { attribute }, ( function | external )
            | structure | alias | constant ;
attribute   = "公開" | "不返" | "節", ident | "記號", ident ;
function    = "術曰", ident, { param }, [ "返", type ], block, "終術" ;
external    = "外術曰", ident, { param }, [ "返", type ], [ "記號", ident ], "終外術" ;
param       = "受", ident, "之", type ;
structure   = "構", ident, { ident, "之", type }, "終構" ;
alias       = "別名", ident, "為", type ;
constant    = "常", ident, "之", type, "為", expr ;

block       = { statement } ;
statement   = local | assign | call_stmt | if_stmt | while_stmt
            | return_stmt | unsafe_stmt | expr_stmt ;
local       = "設", ident, "之", type, "為", expr ;
assign      = "置", lvalue, "為", expr ;
call_stmt   = "行", ident, "以", "(", [ args ], ")" ;
if_stmt     = "若", expr, "則", block, [ "否則", block ], "終若" ;
while_stmt  = "當", expr, "則", block, "終當" ;
return_stmt = "歸", [ expr ] ;
unsafe_stmt = "險", block, "終險" ;
expr_stmt   = expr ;                  (* 寫揮發・障壁など値を使わない式 *)

type        = "無符八" | "無符十六" | "無符三二" | "無符六四"
            | "有符八" | "有符十六" | "有符三二" | "有符六四"
            | "真偽" | "無"
            | "指標", "〈", type, "〉"
            | "列陣", "〈", type, ",", integer, "〉"
            | ident ;                 (* 構造体名・別名 *)

expr        = primary | unary | expr, binop, expr ;   (* 優先順位は下表 *)
unary       = ( "負" | "非" | "位非" ), expr ;
primary     = integer | string | "真" | "偽" | "空" | ident
            | "(", expr, ")"
            | "呼", ident, "以", "(", [ args ], ")"
            | "取址", "(", lvalue, ")" | "取值", "(", expr, ")"
            | "轉", "〈", type, "〉", "(", expr, ")"
            | "讀揮發", "〈", type, "〉", "(", expr, ")"
            | "寫揮發", "〈", type, "〉", "(", expr, ",", expr, ")"
            | "障壁", "〈", [ ident ], "〉", "(", ")"
            | "長度", "(", expr, ")"
            | lvalue_expr ;
lvalue_expr = "欄", "(", lvalue, ",", ident, ")" | "項", "(", lvalue, ",", expr, ")" ;
lvalue      = ident | "取值", "(", expr, ")" | lvalue_expr ;
args        = expr, { ",", expr } ;
binop       = "乘" | "除" | "餘" | "加" | "減" | "左移" | "右移"
            | "小於" | "小等" | "大於" | "大等" | "等於" | "不等"
            | "位與" | "位異" | "位或" | "且" | "或" ;
integer     = digit, { digit } | ( "0x" | "0X" ), hexdigit, { hexdigit } ;
ident       = "「", ident_char, { ident_char }, "」" ;
string      = "『", { char | escape }, "』" ;
```
- 関数呼び出しの `以` は予約語ではなく、`行「名」以(…)`・`呼「名」以(…)` の定形としてのみ現れる。
- `記號` は属性として関数の前に置くか（`公開 記號「sym」 術曰…`）、`外術曰…` の末尾に置く。
- 属性は任意の順で複数併記できる。

演算子優先順位（高→低）: `乘 除 餘`; `加 減`; `左移 右移`; `小於 小等 大於 大等`; `等於 不等`; `位與`; `位異`; `位或`; `且`; `或`。同順位は左結合。**比較演算子（小於・小等・大於・大等、等於・不等）は連鎖不可**で、`甲 小於 乙 小於 丙` は構文エラー `E0008`。`非`、`位非`、`負` は単項。論理且/或は短絡評価。EBNFのexprはこの優先順位で実装する。

## 5. 関数・制御フロー
- 引数は値渡し、評価順は左から右。局所変数は関数スコープ。名前の再宣言は禁止。
- `歸` は関数から戻る。`返 型` は戻り値型宣言（旧草案の `返「址」之指標` は廃止）。
- `無` 以外の関数は全経路で値を返すこと。返さない経路があれば `E0011`。`若` は `否則` があり両方が返す場合、`險` は中が返す場合だけ全経路とみなす。`當` は 0 回かもしれないので数えない。`不返` の関数は対象外。再帰は許可する。
- 外部関数は `外術曰「名」 ... 終外術`、C ABI (AAPCS64) とする。可変長引数はM0対象外。

## 6. ポインタ・安全性・MMIO
- 生ポインタのデリファレンス、整数⇄ポインタ変換、MMIO、inline asmは `險 ... 終險` 内のみ許可。
- `轉〈指標〈T〉〉(整数)` はunsafeでのみ許可。アドレスは仮想アドレスとして解釈する。物理アドレスからの変換は別途ページマップを要する。
- `讀揮發〈T〉(指標〈T〉)` / `寫揮發〈T〉(指標〈T〉, T)` はvolatile MMIO組込み。TはM0では整数型のみ。
- `障壁〈種〉()` はコンパイラ/CPUバリア組込み。AArch64のDMB/DSB/ISBの選択とドメインは別表で固定し、勝手に置換しない。
  現在の実装は LLVM の `fence` に写す暫定表: `シーケンス`=seq_cst、`リリース`=release、`読み書き`=acq_rel、`_acquire`=acquire、それ以外=seq_cst。DMB/DSB/ISB の対応表は未確定（M1 以降）。
- volatileは排他制御や通常RAMのデータ競合を解決しない。並行性/atomicはM1以降に追加。
- アラインメント違反・不正ポインタはunsafe側の責任とし、M0での安全性は保証しない。

## 7. ABIとコード生成
- ターゲット: aarch64-none-elf, little endian, 64bit、AAPCS64。
- 関数引数はAAPCS64のx0..x7など、戻り値はx0など。スタックは16byte整列。
- `外術` は外部シンボル名をUTF-8識別子から直接導くのではなく、別途 `記號「ascii_symbol」` 指定が必要。外部リンカシンボルはASCII。
- `記號` は `外術曰` の外部シンボル指定だけでなく、`公開 記號「ascii」 術曰「名」…終術` の形で定義済み関数の ELF シンボルを上書きするのにも使う。アセンブリから機械漢文の関数（例: 例外ハンドラ `exception_dispatch`）を呼ぶ場合に必要である。
- `節「.text.boot」`、`公開`、`不返` の属性を関数宣言直前に付与可能とする。属性は宣言前に空白区切りで複数併記できる。
- M0ではコンパイラがLLVM IRを生成し、clang/LLVMツールチェーンでELFをリンクする。
- freestandingでlibc非依存。必要なメモリコピー等のコンパイラ補助ルーチンは明示提供。
- 例外ベクタと初期スタック設定は暫定AArch64アセンブリを許可する。

## 8. エラーと診断
- コンパイル診断は `錯 E0001: 行:列: 説明` の形式、UTF-8位置をコードポイント列で報告する。
- 診断コード（番号は安定させる。`tests/lang/err/` が各コードを検証する）:

  | コード | 意味 | 例 |
  |---|---|---|
  | `E0001` | 型の不一致・型エラー | 初期値・代入・引数・戻り値・条件の型違い、符号違いの整数の演算、整数→ポインタの暗黙変換 |
  | `E0002` | `險` の外での低水準操作 | 生ポインタの `取值`、整数⇄ポインタの `轉`、`讀揮發`/`寫揮發`、`障壁`、ポインタの添字 `項` |
  | `E0003` | 未宣言・再宣言 | 未宣言の変数・関数・構造体・フィールド、変数の再宣言 |
  | `E0004` | 定数の値が宣言した型に合わない（参照した側で報告） | `常「定」之真偽 為 1` を使う |
  | `E0005` | 未初期化値の読み出し | `設「甲」之無符六四 為 甲` |
  | `E0006` | 呼び出しの引数の個数が合わない | `行「乙」以(1, 2)`（乙は引数 1 個） |
  | `E0007` | 配列の定数添字が範囲外 | `項(列, 9)`（長さ 4） |
  | `E0008` | 構文エラー | 式が無い、`終術` が無い、比較演算子の連鎖、宣言として不正 |
  | `E0009` | 字句エラー | 不正なエスケープ、閉じない文字列、識別子内の不正な文字 |
  | `E0010` | 整数リテラルが型の範囲外・64 ビットに収まらない | `無符八` に `300` |
  | `E0011` | 全経路で値を返さない | `若` だけで `否則` が無い関数 |
- ランタイムエラー型 `果〈T,錯〉` はライブラリ型としてM1以降に定義。M0は戻り値・明示分岐で処理。
- POSIX errno対応は漢令ABI層で定義し、コンパイラ言語仕様には混ぜない。

## 9. 最小UARTコード例（M0草案）
```text
外術曰「核外輸出」 受「址」之指標〈無符八〉 受「長」之無符六四 返 無 終外術

術曰「核主」 返 無
    險
        行「核外輸出」以(取址(「世界安寧」), 12)
    終險
終術
```
上例は概念を示すのみ。M0仕様では文字列からポインタへの変換・UTF-8バイト列長取得・文字列アドレス取得の規則を以下のように固定する:
- `『世界安寧』` の型は不変バイト配列 `列陣〈無符八,12〉`、末尾NULなし。
- `取址(『世界安寧』)` は先頭バイトの `指標〈無符八〉` を返す。
- `長度(『世界安寧』)` はコンパイル時定数12を返す。
したがって正式な例は次の通り:
```text
外術曰「核外輸出」 受「址」之指標〈無符八〉 受「長」之無符六四 返 無 終外術
術曰「核主」 返 無
    行「核外輸出」以(取址(『世界安寧』), 長度(『世界安寧』))
終術
```
`核外輸出` は暫定ブートUARTルーチンであり、次段階では機械漢文のMMIOドライバへ置換する。

## 11. 機械漢文によるMMIOドライバ（実装済み, M2）

`外術曰` に頼らず、PL011 UART ドライバ全体を機械漢文で記述できる。要点:

- 生ポインタの添字参照 `項(指標〈T〉, i)` は要素 `i` を読み出す（`險` 内のみ）。
- アドレス定数のポインタ化は `轉〈指標〈T〉〉(整数)`（`險` 内のみ）。
- レジスタ読み書きは `讀揮發〈T〉(ptr)` / `寫揮發〈T〉(ptr, 値)`。
- 整数リテラルは使用文脈の整数型に適合する（例: `無符六四` 変数への `0`、比較 `… 不等 0`）。
- この形の実例は `tests/uart_mmio.mkn`（`make test` が QEMU で「世界安寧」を検証）。

```text
術曰「核外輸出」 受「址」之指標〈無符八〉 受「長」之無符六四 返 無
    設「資料」之無符六四 為 150994944   註 UART_DR 0x09000000
    設「狀態」之無符六四 為 150994968   註 UART_FR 0x09000018
    設「序」之無符六四 為 0
    當 序 小於 長 則
        險
            設「資址」之指標〈無符三二〉 為 轉〈指標〈無符三二〉〉(資料)
            設「狀址」之指標〈無符三二〉 為 轉〈指標〈無符三二〉〉(狀態)
            當 (讀揮發〈無符三二〉(狀址) 位與 32) 不等 0 則 終當
            寫揮發〈無符三二〉(資址, 轉〈無符三二〉(項(址, 序)))
        終險
        置「序」為 序 加 1
    終當
終術
```

コード生成上の注意: 生成するLLVM IRは、二項演算・`icmp` の右オペランド型を省略する
新しいテキスト表現（LLVM 21以降で必須、本リポジトリはLLVM 23で検証）に従う。

## 12. 例外ハンドラと MMU の実装例（M2）

漢極 `kernel/kernel.mkn` は、`記號` でアセンブリに露出した機械漢文関数により
例外診断とメモリ管理を行う。要点:

- 例外の入口（ベクタ表・レジスタ保存・`ELR_EL1`/`ESR_EL1` の受け渡し）は暫定
  アセンブリ `kernel/vectors.S`。
- 診断は機械漢文 `公開 記號「exception_dispatch」 術曰「異常處理」…`。
  `受「異常値」之無符六四`（=ESR_EL1）を復号して出力し、BRK を飛び越えるため
  `歸 復歸址 加 4`（=`ELR_EL1`+4）を返す。
- システムレジスタ操作は `外術曰…記號「enable_mmu」/「read_sctlr」` で
  `kernel/sysreg.S` に委譲し、変換表の構築は機械漢文（`設頁表`）が
  `寫揮發〈無符六四〉` で行う。

```text
公開 記號「exception_dispatch」 術曰「異常處理」 受「異常値」之無符六四 受「復歸址」之無符六四 返 無符六四
    行「核外輸出」以(取址(『異常捕獲 ESR=』), 長度(『異常捕獲 ESR=』))
    行「核外十六」以(異常値)
    歸 復歸址 加 4
終術

術曰「核外十六」 受「値」之無符六四 返 無
    行「核外字元」以(48)
    行「核外字元」以(120)
    設「回」之無符六四 為 0
    當 回 小於 16 則
        設「段」之無符六四 為 15 減 回
        設「半」之無符六四 為 (値 右移 (段 乘 4)) 位與 15
        若 半 小於 10 則
            行「核外字元」以(轉〈無符八〉(半 加 48))
        否則
            行「核外字元」以(轉〈無符八〉(半 加 87))
        終若
        置「回」為 回 加 1
    終當
    行「核外字元」以(10)
終術
```

注: 先頭が予約語と衝突する裸の識別子（例: `餘位` は `餘`=減算余り）は
字句解析で分割される。その場合は `「餘位」` と括るか、衝突しない名を用いる。

## 13. 後続拡張（非M0）

- 低水準漢文命令でブートアセンブリを置換。
