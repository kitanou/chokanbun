# 機械漢文言語仕様 v0.1（草案）

## 目的
Cの漢字置換に留まらない、型安全性と低水準制御を持つシステム記述言語を設計する。

## 構文案（未実装）
```text
術曰「核主」
    出力「世界安寧」
終術
```

```text
術曰「配記憶」
    受「長」之無符整數
    返「址」之指標
    若「長」為零
        返空
    終若
    求空閑頁
    返其址
終術
```
上記の「出力」「求空閑頁」は組込みかライブラリ関数か未決定。

## 必須言語機能
- 整数（符号あり/なし、8/16/32/64bit）、真偽、ポインタ、配列、構造体
- 関数、引数、戻り値、ローカル変数、定数、条件分岐、ループ
- アラインメント、メモリレイアウト、volatile MMIO
- unsafeに相当する低水準操作の明示
- C ABI連携、no_std相当、リンカセクション指定
- 組込みアセンブリまたは専用低水準命令（将来）

## コンパイルパイプライン
UTF-8字句解析 → 構文解析 → 名前解決/型検査 → 型付き機械漢文IR → LLVM IR → AArch64 ELF

## 仕様確定が必要な事項
識別子、字句区切り、文字列リテラル、演算子、所有権/寿命、エラー処理、ABI、Unicode正規化、診断メッセージ。
