# 漢文OS原則の対応表（Issue #7）

[detailed-design-v0.2.md](detailed-design-v0.2.md) の 4 原則を、実装箇所（ファイル）と、それを確かめる QEMU 試験（`tests/run_tests.sh` の `kernel qemu: …`）に対応づける。2026-11-04 時点。「ずれ」の列は、設計の文言と実装が違う所、または試験が足りない所。

## 1. 萬物皆文 — 名前空間を統一して表す

「全てを通常ファイルと同一視する意味ではない」（detailed-design）。名前（パス）で引ける対象を篇藏に揃え、柄（ファイル記述子）で読み書きする。

| 対象 | 実装 | 試験 | ずれ |
|---|---|---|---|
| ファイル（篇）の階層名前空間 | `kernel/vfs/pian.mkn`（`天地/…`、章・篇・予約章）、`kernel/vfs/tag.mkn`（標・索） | 篇藏 F1〜F4、殻 章・移・在・改、競合のストレス | — |
| 装置 | `天地/器/盤`（UART）。`開` で盤の柄になる。`pian.mkn` | 篇藏 器/盤 への書込が UART に出る | 器は盤だけ。ブロック装置・表示装置・入力装置は篇として開けない（漢令・BTRON3 の `opn_dev` で扱う） |
| 実行可能な命令 | `天地/術`（埋め込みの漢像を 術 として登録）。`kernel/proc/spawn.mkn` の `術探` | 殻から外部命令 問安 を起動、像の無い命令は 殻不明 | — |
| 行程の情報 | 行程表（`kernel/kernel.mkn`）、`prc_sts`（`kernel/proc/term.mkn`）は漢令でだけ読める | 強制終了・行程状態 | **名前空間には出ていない**（`天地/…` 配下に行程の篇は無い） |
| 標準入出力・管・典籍を同じ柄で | `kernel/vfs/handle.mkn`（柄 → 開表 → 種: 盤・篇・管）、`kernel/vfs/pipe.mkn`、`複寫柄`（漢令 20） | 柄表・開表、管、殻の傳・奏入 | — |
| 時刻・メモリなど | 漢令（名前では引けない） | 時計、メモリ管理 | 設計どおり（統一名前空間の対象は文・装置・命令） |

## 2. 百官各司 — 官司ごとに責務と境界

設計の表（detailed-design「用語と実装」）の配置は `kernel/scheduler/` などだが、実装は少数の大きなファイルに分かれている。責務は対応するが、**ディレクトリ名は設計と違う**。

| 官司 | 責務 | 実装 | 試験 |
|---|---|---|---|
| 天道（スケジューラ） | 次程・優先度・時刻待ち・横取り | `kernel/kernel.mkn`（`次程`・`排程`・割込切替）、`kernel/proc/term.mkn`（優先度）、`kernel/proc/clk.mkn` | 譲渡によるラウンドロビン、タイマー横取り、待機と起床、長時間 |
| 戶籍（行程管理） | 生成・終了・待機・柄表・親子 | `kernel/proc/spawn.mkn`（生行程・待行程・換行程・副行程）、`kernel/kernel.mkn`（行程表） | 生行程・待行程、行程表、行程表の枯渇、起動・回収を 20 回、換行程 |
| 度支（記憶管理） | 頁池・行程ごとの窓・デマンドページング・塊 | `kernel/kernel.mkn`（頁取・頁放・設頁表）、`kernel/proc/mem.mkn`（塊・広域） | physical page allocator、頁池 割当・解放、デマンドページング、行程ごとのアドレス空間、頁池 120 MiB、メモリ管理 |
| 典籍（VFS・ファイル） | 篇藏、柄、録層、永続化 | `kernel/vfs/`、`kernel/file/btron.mkn`（BTRON3 録層） | 篇藏 F1〜F4、典籍の各試験、録層、vda（永続化）、差分書き込み |
| 驛傳（IPC・pipe） | メッセージ、同期、管 | `kernel/proc/msg.mkn`・`msgh.mkn`・`sync.mkn`・`sync2.mkn`、`kernel/vfs/pipe.mkn` | メッセージ、メッセージハンドラ、セマフォ・イベントフラグ、管、殻の傳・奏入 |
| 刑律（権限・エラー体系） | 利用者情報、篇の權、誤り番号 | `kernel/proc/user.mkn`、`kernel/vfs/pian.mkn`（權・予約章・法）、誤り定数は `kernel/kernel.mkn`・`kernel/vfs/const.mkn` | 利用者情報・時刻設定の権限、篇藏（權）、強制終了 |
| 百官（ドライバ） | UART、GIC、タイマー、virtio、RTC | `kernel/kernel.mkn`（UART・GIC・タイマー）、`kernel/proc/blk.mkn`・`gpu.mkn`・`inp.mkn`・`dev.mkn`・`fdt.mkn` | GICv2 timer IRQ、UART 入力の 読込、表示装置、入力装置、vda、Devicetree |

ずれ: 官司が 1 つのファイルに閉じていない（`kernel/kernel.mkn` に天道・戶籍・度支・刑律の一部が同居）。分けるかどうかは未決。

## 3. 令出必行 — 漢令の意味・型・失敗条件を規範的に定義

| 要求 | 実装・文書 | 試験 | ずれ |
|---|---|---|---|
| 番号・引数・戻り値・誤りを規範として固定 | [abi-aarch64.md](abi-aarch64.md) の漢令一覧 | 漢令ごとの試験（下記） | 文書に載る漢令と実装の番号の突き合わせは手作業（自動検査は無い） |
| 未知の番号は拒否 | `kernel/kernel.mkn` の許可リスト | 未知の漢令番号を -ENOSYS で拒否 | 新しい番号を足すとき許可リストへの追加を忘れる誤りが起きた（管の実装中）。番号表との照合試験は無い |
| 引数の範囲検査 | `窓内`・`備宛`（`kernel/kernel.mkn`） | 核専用域への 書出・読込 を -EFAULT で拒否、長さの上限超過を -EFAULT で拒否、読込 が書込先の頁を先に張る | — |
| 型・意味が仕様どおり | 各漢令の処理 | 典籍・柄・生行程・管・換行程の各試験。BTRON3 は互換層ごと | BTRON3 API は規範条件との照合が途中（[compat/btron3-conformance.md](compat/btron3-conformance.md)） |

## 4. 異常必奏 — エラーを明示して診断情報を失わない

| 要求 | 実装 | 試験 | ずれ |
|---|---|---|---|
| 失敗は黙らず負の誤り番号で返す | 全漢令（x0 に負値）、`錯換`（BTRON3 の ER_* への変換） | 典籍の誤り経路、殻 書 の誤り経路、BTRON3 互換層 get_tid ほか | — |
| 例外を診断して続ける | `kernel/proc/exc.mkn`（`def_exc`）、例外診断（ESR_EL1 の復号） | exception handler caught BRK、resumed after exception、例外ハンドラ | — |
| 異常な行程だけを止め、他を壊さない | 異常終了の処理（BRK などは子だけを強制終了） | 異常終了とメモリ保護 | — |
| 回復不能は理由を出して止まる | `核恐慌`（`記憶不足`・`init終了`）、導の `導誤 理由` | Devicetree（RAM 16 MiB で 核恐慌 記憶不足）、独立ブートローダー（失敗の理由） | — |
| 資源の枯渇で壊れない | 頁・行程・柄・管の枯渇を誤りで返す | 頁不足の 生行程、行程表の枯渇、柄表の満杯、管（-EMFILE） | — |
| 子の失敗を親が知る | 終了コード、`殻碼`・`殻誤`・`殻不明` の区別 | 殻から外部命令…、像の無い命令は 殻不明 | — |
| 診断の記録 | 起動時の出力、`日誌`（`頁割当` など）のみ | 起動ログの検査 | **持続する診断ログ（`志` への記録）は殻・核とも自動では行わない** |

## 5. 抜けの洗い出し

実装も試験も無い（または設計と食い違う）項目:

1. **行程の情報を名前空間に出す**（萬物皆文）: `天地/…` 配下に行程の篇が無い。BTRON3 の `prc_sts` と漢令でだけ読める。
2. **官司ごとのファイル分割**（百官各司）: 設計の `kernel/scheduler/` などと実装が違う。分けるか、設計を実装に合わせるかを決める。
3. **漢令の番号表と許可リストの照合**（令出必行）: 文書・許可リスト・処理の三者の食い違いを検出する試験が無い。管の実装中に 1 度起きた。
4. **持続する診断ログ**（異常必奏）: 例外・`殻碼` などを `天地/志` に自動で残す仕組みが無い。

どれも他の作業を止めるものではない。1・4 は設計の判断が要るので、着手するときに個別の Issue にする。
