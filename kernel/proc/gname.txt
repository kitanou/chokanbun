註 グローバル名管理 (BTRON3 互換層 1.4。設計は docs/compat/btron3-compat-layer.md §4)。
註 名前 (最大 8 文字の TC = 16 ビット文字、TNULL 終端) → 32 ビット値の対応を、行程と独立に保つ。
註 漢令: 112 名作(名址,値,指定)  113 名削(名址)  114 名取(名址,宛址)。
註 名前の正規形: 先頭 8 文字だけを使い (BTRON3 は 8 文字を超える部分を無視する)、TNULL 以降は 0 で詰めた
註 2 語 (甲=文字 0..3、乙=文字 4..7。文字 n は 16*(n mod 4) ビット目)。名前が空なら -EINVAL。

常「名限」之無符六四 為 16            註 グローバル名の最大数
常「名表址」之無符六四 為 1077805056   註 0x403E0000 グローバル名表 (48 B × 名限)
常「名札址」之無符六四 為 1077805824   註 0x403E0300 名正 が正規形を置く作業語 (+0 甲, +8 乙)
常「名項幅」之無符六四 為 48           註 +0 使用 (0/1), +8 名甲, +16 名乙, +24 値 (下位 32 ビット), +32 DELEXIT の持ち主の識 (0=なし)
常「名既定」之無符六四 為 0x8000       註 DELEXIT (指定の最上位)
常「誤存」之無符六四 為 18446744073709551599   註 -EEXIST(17) 名前が既にある
常「誤引」之無符六四 為 18446744073709551594   註 -EINVAL(22) 引数が不正 (空の名前・不正な指定)

術曰「名項址」 受「序」之無符六四 返 無符六四
    歸 名表址 加 (序 乘 名項幅)
終術

術曰「名表初期化」 返 無
    設「序」之無符六四 為 0
    當 序 小於 名限 則
        險
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(呼「名項址」以(序)), 0)
        終險
        置「序」為 序 加 1
    終當
終術

註 民の名前 (TC 配列) を読み、正規形を 名札 に置く。0 = 成功、負 = 誤り (-EFAULT / -EINVAL)。
術曰「名正」 受「址」之無符六四 返 無符六四
    設「甲」之無符六四 為 0
    設「乙」之無符六四 為 0
    設「序」之無符六四 為 0
    設「止」之無符六四 為 0
    當 (序 小於 8) 且 (止 等於 0) 則
        若 呼「窓内」以(址 加 (序 乘 2), 2) 等於 0 則
            歸 誤範囲
        終若
        設「字」之無符六四 為 0
        險
            置「字」為 轉〈無符六四〉(讀揮發〈無符十六〉(轉〈指標〈無符十六〉〉(址 加 (序 乘 2))))
        終險
        若 字 等於 0 則
            置「止」為 1
        否則
            若 序 小於 4 則
                置「甲」為 甲 位或 (字 左移 (序 乘 16))
            否則
                置「乙」為 乙 位或 (字 左移 ((序 減 4) 乘 16))
            終若
            置「序」為 序 加 1
        終若
    終當
    若 (甲 等於 0) 且 (乙 等於 0) 則
        歸 誤引
    終若
    險
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址), 甲)
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址 加 8), 乙)
    終險
    歸 0
終術

註 名札の名前を持つ項の番号。無ければ 全一。
術曰「名探」 返 無符六四
    設「甲」之無符六四 為 0
    設「乙」之無符六四 為 0
    險
        置「甲」為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址))
        置「乙」為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址 加 8))
    終險
    設「序」之無符六四 為 0
    當 序 小於 名限 則
        設「枠」之無符六四 為 呼「名項址」以(序)
        險
            若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠)) 等於 1 則
                若 (讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 8)) 等於 甲) 且 (讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 16)) 等於 乙) 則
                    歸 序
                終若
            終若
        終險
        置「序」為 序 加 1
    終當
    歸 全一
終術

註 名作: 指定の下位が 0=N_CREATE (既にあれば -EEXIST)、1=N_MODIFY (無ければ -ENOENT)、2=N_FORCE。
註 それ以外の値は -EINVAL。最上位 (0x8000) は DELEXIT で、持ち主を呼出側にする (指定が無ければ持ち主は変えない)。
術曰「名作処理」 受「址」之無符六四 受「値」之無符六四 受「指定」之無符六四 返 無符六四
    設「結」之無符六四 為 呼「名正」以(址)
    若 結 不等 0 則
        歸 結
    終若
    設「基」之無符六四 為 指定 位與 0x7FFFFFFF
    若 基 大於 2 則
        歸 誤引
    終若
    設「序」之無符六四 為 呼「名探」以()
    設「枠」之無符六四 為 0
    若 序 等於 全一 則
        若 基 等於 1 則
            歸 誤無物
        終若
        置「序」為 0
        當 (序 小於 名限) 且 (枠 等於 0) 則
            險
                若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(呼「名項址」以(序))) 等於 0 則
                    置「枠」為 呼「名項址」以(序)
                終若
            終險
            置「序」為 序 加 1
        終當
        若 枠 等於 0 則
            歸 誤満
        終若
        險
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠), 1)
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 8), 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址)))
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 16), 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(名札址 加 8)))
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 32), 0)
        終險
    否則
        若 基 等於 0 則
            歸 誤存
        終若
        置「枠」為 呼「名項址」以(序)
    終若
    險
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 24), 値 位與 0xFFFFFFFF)
        若 (指定 位與 名既定) 不等 0 則
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 32), 呼「讀欄」以(呼「讀現在」以(), 偏識))
        終若
    終險
    歸 0
終術

註 名取: 値 (下位 32 ビット) を 宛 の 4 バイトへ書く。宛は書込可能な窓内でなければ -EFAULT。
術曰「名取処理」 受「址」之無符六四 受「宛」之無符六四 返 無符六四
    設「結」之無符六四 為 呼「名正」以(址)
    若 結 不等 0 則
        歸 結
    終若
    若 呼「備宛」以(宛, 4) 不等 1 則
        歸 誤範囲
    終若
    設「序」之無符六四 為 呼「名探」以()
    若 序 等於 全一 則
        歸 誤無物
    終若
    險
        設「値」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(呼「名項址」以(序) 加 24))
        寫揮發〈無符三二〉(轉〈指標〈無符三二〉〉(宛), 轉〈無符三二〉(値))
    終險
    歸 0
終術

術曰「名終了」 受「識」之無符六四 返 無
    設「序」之無符六四 為 0
    當 序 小於 名限 則
        設「枠」之無符六四 為 呼「名項址」以(序)
        險
            若 (讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠)) 等於 1) 且 (讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠 加 32)) 等於 識) 則
                寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(枠), 0)
            終若
        終險
        置「序」為 序 加 1
    終當
終術
