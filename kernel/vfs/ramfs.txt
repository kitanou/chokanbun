註 ---- 典籍 (RAMFS/VFS) ----------------------------------------------------
註 目録項目 目 の配置: +0 名前(16 B), +16 名長 (0 = 削除済みの墓標), +24 体長, +32 (未使用), +40 開数 (開いている開表項の数)。
註 柄: 0=標準入力 (コンソール), 1/2=標準出力/誤り, 3+番号=開いた典籍。

註 典籍に 1 件を加える (起動時の初期化用)。番号を返す。
術曰「籍入」 受「名址」之指標〈無符八〉 受「名長」之無符六四 受「体址」之指標〈無符八〉 受「体長」之無符六四 返 無符六四
    險
        設「名数」之無符六四 為 轉〈無符六四〉(名址)
        設「体数」之無符六四 為 轉〈無符六四〉(体址)
        設「数」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址))
        若 数 小於 籍限 則
            設「目」之無符六四 為 籍表址 加 (数 乘 籍項幅)
            設「序」之無符六四 為 0
            當 序 小於 名長 則
                寫揮發〈無符八〉(轉〈指標〈無符八〉〉(目 加 序), 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(名数 加 序)))
                置「序」為 序 加 1
            終當
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 16), 名長)
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 24), 体長)
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 32), 0)
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 40), 0)
            設「体」之無符六四 為 籍体址 加 (数 乘 籍体幅)
            置「序」為 0
            當 序 小於 体長 則
                寫揮發〈無符八〉(轉〈指標〈無符八〉〉(体 加 序), 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(体数 加 序)))
                置「序」為 序 加 1
            終當
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址), 数 加 1)
            歸 数
        終若
        歸 誤柄
    終險
終術

註 目録項目 目 の名前が (名址, 名長) と一致するか。
術曰「名合」 受「目」之無符六四 受「名址」之無符六四 受「名長」之無符六四 返 無符六四
    險
        若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 16)) 不等 名長 則
            歸 0
        終若
        設「序」之無符六四 為 0
        當 序 小於 名長 則
            若 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(目 加 序)) 不等 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(名址 加 序)) 則
                歸 0
            終若
            置「序」為 序 加 1
        終當
        歸 1
    終險
終術

註 名前 (名址, 名長) に一致する典籍の目録番号を返す。無ければ 全一。
術曰「籍検」 受「名址」之無符六四 受「名長」之無符六四 返 無符六四
    險
        設「数」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址))
        設「序」之無符六四 為 0
        當 序 小於 数 則
            若 呼「名合」以(籍表址 加 (序 乘 籍項幅), 名址, 名長) 等於 1 則
                歸 序
            終若
            置「序」為 序 加 1
        終當
        歸 全一
    終險
終術

註 典籍を作る (既にあれば内容を空にする)。成功で 0、満杯は -ENOSPC、名前が不正は -EFAULT。
術曰「籍作」 受「名址」之無符六四 受「名長」之無符六四 返 無符六四
    若 (名長 等於 0) 或 (名長 大於 16) 則
        歸 誤範囲
    終若
    險
        設「数」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址))
        設「序」之無符六四 為 0
        當 序 小於 数 則
            設「目」之無符六四 為 籍表址 加 (序 乘 籍項幅)
            若 呼「名合」以(目, 名址, 名長) 等於 1 則
                寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 24), 0)
                寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 32), 0)
                寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 40), 0)
                歸 0
            終若
            置「序」為 序 加 1
        終當
        註 削除済みの枠 (名長 0) があれば再利用する。無ければ末尾に足す。
        設「枠」之無符六四 為 数
        置「序」為 0
        當 序 小於 数 則
            若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍表址 加 (序 乘 籍項幅) 加 16)) 等於 0 則
                若 枠 等於 数 則
                    置「枠」為 序
                終若
            終若
            置「序」為 序 加 1
        終當
        若 枠 大等 籍限 則
            歸 誤満
        終若
        設「新」之無符六四 為 籍表址 加 (枠 乘 籍項幅)
        置「序」為 0
        當 序 小於 名長 則
            寫揮發〈無符八〉(轉〈指標〈無符八〉〉(新 加 序), 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(名址 加 序)))
            置「序」為 序 加 1
        終當
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(新 加 16), 名長)
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(新 加 24), 0)
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(新 加 32), 0)
        寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(新 加 40), 0)
        若 枠 等於 数 則
            寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址), 数 加 1)
        終若
        歸 0
    終險
終術

註 典籍を削る。成功で 0、無い名前は -ENOENT、開かれていれば -EBUSY。
註 枠は名長 0 の墓標にして再利用できる (柄 = 3 + 枠番号 は変わらない)。
術曰「籍削」 受「名址」之無符六四 受「名長」之無符六四 返 無符六四
    險
        設「数」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址))
        設「序」之無符六四 為 0
        當 序 小於 数 則
            設「目」之無符六四 為 籍表址 加 (序 乘 籍項幅)
            若 呼「名合」以(目, 名址, 名長) 等於 1 則
                若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 40)) 不等 0 則
                    歸 誤忙
                終若
                寫揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 16), 0)

註 目録の 序 番目 (削除済みを数えない) の名前を 宛 へ写し、名前の長さを返す。範囲外は -ENOENT。
術曰「籍目」 受「序」之無符六四 受「宛」之無符六四 受「長」之無符六四 返 無符六四
    險
        設「総」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍数址))
        設「見」之無符六四 為 0
        設「枠」之無符六四 為 総
        設「走」之無符六四 為 0
        當 (走 小於 総) 且 (枠 等於 総) 則
            若 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(籍表址 加 (走 乘 籍項幅) 加 16)) 不等 0 則
                若 見 等於 序 則
                    置「枠」為 走
                終若
                置「見」為 見 加 1
            終若
            置「走」為 走 加 1
        終當
        若 枠 等於 総 則
            歸 誤無物
        終若
        設「目」之無符六四 為 籍表址 加 (枠 乘 籍項幅)
        設「名長」之無符六四 為 讀揮發〈無符六四〉(轉〈指標〈無符六四〉〉(目 加 16))
        若 名長 大於 長 則
            置「名長」為 長
        終若
        設「巡」之無符六四 為 0
        當 巡 小於 名長 則
            寫揮發〈無符八〉(轉〈指標〈無符八〉〉(宛 加 巡), 讀揮發〈無符八〉(轉〈指標〈無符八〉〉(目 加 巡)))
            置「巡」為 巡 加 1
        終當
        歸 名長
    終險
終術
