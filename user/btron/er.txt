註 【選択の記録】BTRON3仕様書 Ver.3.20.00 は ER_* の名称と意味を規定するが、数値を規定していない
註 (共有データ編 data_type.html は ErrCode = 符号付き 16 ビットの eclass と 16 ビットの detail の共用体、
註  OS仕様編の各節は名称のみ)。そのため数値は実装依存として次のとおり選ぶ。
註   ER_x = (eclass << 16) | detail、eclass = -1 (0xFFFF)、detail = 下の通し番号 (1 始まり)。
註   リトルエンディアンの ErrCode 共用体 (detail が下位 16 ビット) と一致し、全て負の W になる。
註   x0 には符号拡張した 64 ビット値で返す。
註 理由: 負値であること (呼出し側の WERR 判定) だけが規範から言え、数値の細部は他に根拠がない。
註 名称が増えるときは末尾に足す (通し番号を変えない)。

註 対応が定まらないものは ER_PAR にする (ER_PAR = 引数が不正)。対応表は次の表のとおり。
註   -ENOENT(2) → ER_NOEXS   -EBADF(9) → ER_FD    -ENOMEM(12) → ER_NOMEM  -EBUSY(16) → ER_BUSY

註   -EAGAIN(11) → ER_LIMIT  -ENOEXEC(8) → ER_REC  その他 (-ENOSYS を含む) → ER_PAR
